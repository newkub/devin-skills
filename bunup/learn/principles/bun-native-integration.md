# Bun Native Integration

## Bun-First Design

Bunup ออกแบบมาเพื่อทำงานกับ Bun:
- **Native APIs** - ใช้ Bun's native APIs
- **Performance** - ใช้ประโยชน์จาก Bun's performance
- **Tooling** - integrate กับ Bun's tooling

## Benefits

- **Speed** - เร็วกว่า bundlers อื่นๆ
- **Consistency** - ใช้ toolchain เดียวกัน
- **Simplicity** - ไม่ต้อง install tools เพิ่ม

## Usage

```bash
bun add bunup
bun run build
```
