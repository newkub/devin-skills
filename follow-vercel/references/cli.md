# Vercel - CLI Reference

Commands และ options สำหรับ Vercel CLI

## หมวดหมู่

- Installation - Install Vercel CLI
- Core Commands - vercel, vercel --prod, vercel dev
- Authentication - login, logout, switch, whoami
- Project Management - init, link, list, inspect, rm
- Deployment - deploy, build options, preview URL
- Environment Variables - env add, pull, rm, ls
- Domains - domains add, ls, inspect, move, rm, verify
- Logs & Debugging - logs, inspect
- Teams - teams management, add member
- Secrets - secrets add, ls, rm, rename
- Certificates - certs add, ls, rm
- Aliases - alias, ls, rm
- Configuration - vercel.json, project commands
- Global Options - token, scope, debug, help, version, cwd
- Exit Codes - success, error codes
- Tips - speed up deployment, CI/CD

## สรุป

- `vercel` - Deploy to preview
- `vercel --prod` - Deploy to production
- `vercel dev` - Local development
- `vercel env` - Environment variables
- `vercel domains` - Domain management
- `vercel logs` - View logs
- `vercel teams` - Team management
