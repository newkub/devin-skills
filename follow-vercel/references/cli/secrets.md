# Secrets

## vercel secrets add

Add a secret.

```bash
vercel secrets add [name] [value]
```

## vercel secrets ls

List secrets.

```bash
vercel secrets ls
```

## vercel secrets rm

Remove secret.

```bash
vercel secrets rm [name]
```

## vercel secrets rename

Rename secret.

```bash
vercel secrets rename [old] [new]
```
