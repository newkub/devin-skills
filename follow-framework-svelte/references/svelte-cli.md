## Goal

อ้างอิงคำสั่ง Svelte CLI (`sv`)

## Scope

ใช้เมื่องานเกี่ยวข้องกับ Svelte CLI

## Commands

- `npx sv create <project>` — สร้าง project ใหม่
- `npx sv migrate svelte-5` — auto-migrate จาก Svelte 4 ไป 5
- `npx sv check` — ตรวจสอบ project

## Rules

- ใช้ `npx sv` เวอร์ชันล่าสุด
- ตรวจสอบ backup ก่อน migrate

## Expected Outcome

- ใช้งาน `sv` CLI ถูกต้อง
