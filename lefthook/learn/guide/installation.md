# Installation

วิธีติดตั้ง Lefthook

## Using Bun (Recommended)

```bash
bun add -D lefthook
```

## Using bun

```bash
bun install -D lefthook
```

## Using yarn

```bash
yarn add -D lefthook
```

## Using bun

```bash
bun add -D lefthook
```

## Initialize in Project

```bash
bunx lefthook install
```

This will:
- Create `lefthook.yml` configuration file
- Install Git hooks
- Setup Lefthook in your project

## Verify Installation

```bash
bunx lefthook version
```

## Uninstall

```bash
bunx lefthook uninstall
```

This will:
- Remove Git hooks
- Keep configuration file
