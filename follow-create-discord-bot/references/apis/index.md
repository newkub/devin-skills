# Create Discord Bot API & Dependencies

## Install

```sh
bun add -D discord.js
# or
npm install --save-dev discord.js
```

## Version

- Latest: see registry
- [Package Registry](https://www.npmjs.com/package/discord.js)
- [Repository](https://github.com/discordjs/discord.js)

## Dependencies

- See package registry for transitive dependencies.

## Common API / Commands

| commands | description | default | options |
|---|---|---|---|
| `install` | Install discord.js in project | latest version | --save-dev, --save, --global |
| `import` | Import from 'discord.js' | default or named | (none) |
| `configure` | Configure project settings | project defaults | --config, --file |
| `use` | Use the main API / runtime | as documented | (none) |
