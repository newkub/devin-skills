# delivery

Alias of `release` — stripping the label leaves the `delivery` row, which `release.md` bundles next to `versioning-changelog`, a superset of what this label promises.

## Run

- run `/deep-review <scope> delivery, versioning-changelog` — `release.md` carries both rows and their evidence routes
- the `optimize` scope that reaches this label is `ci` (pipeline time and cost); the measure-then-improve work itself stays `/optimize ci`
- no argument of its own — the caller's `<scope>` is forwarded verbatim
