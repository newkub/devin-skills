# Navigation Review

## Goal

ตรวจ navigation จากมุม stakeholder — โฟกัส wayfinding, IA และ consistency

## Checklist

- User บอกได้ว่าตอนนี้อยู่หน้าไหน (active state, breadcrumb)
- Menu labels ใช้คำที่ user คุ้น ไม่ใช่ jargon ภายใน
- Navigation items ไม่เกิน 7±2 ใน level เดียว
- Back/forward ของ browser ทำงานถูกต้อง
- Deep link ไปยังหน้าย่อยได้และ state ไม่หาย
- Mobile nav เข้าถึงได้ง่ายและไม่บัง content
- Search มีให้เมื่อ content เยอะ
- Footer nav ครบสำหรับลิงก์สำคัญที่ไม่อยู่ใน main nav

## Common Issues

- Hamburger menu ซ่อน nav ทั้งหมดบน desktop
- Active state ไม่ชัดหรือไม่มี
- Route เปลี่ยนแต่ scroll position ไม่ reset
