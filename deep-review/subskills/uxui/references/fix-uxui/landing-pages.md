# Landing Pages Review

## Goal

ตรวจ landing page จากมุม stakeholder — โฟกัส conversion, clarity และ first impression

## Checklist

- Hero section สื่อ value proposition ชัดใน 1 ประโยค
- Primary CTA เห็นได้ทันทีเหนือ fold และมี contrast ชัดเจน
- Headline สื่อสารกับ target audience ไม่ใช่ generic
- Social proof (logos, testimonials, numbers) อยู่ใกล้ CTA
- Secondary CTA ไม่แข่งกับ primary CTA
- รูป/screenshot ของ product เป็นงานจริงไม่ใช่ stock
- Fold แรกตอบคำถาม 3 ข้อ: คืออะไร, ใครใช้, ทำไมต้องสนใจ
- Page load รู้สึกเร็ว — hero content ไม่ shift ระหว่างโหลด

## Common Issues

- CTA หลายตัวแข่งกัน ทำให้ user ไม่รู้ว่าต้องกดอะไร
- Copy เน้น feature มากกว่า benefit
- ไม่มี trust signals เหนือ fold
