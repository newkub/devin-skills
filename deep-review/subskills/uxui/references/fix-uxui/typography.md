# Typography Review

## Goal

ตรวจ typography จากมุม stakeholder — โฟกัส readability และ hierarchy

## Checklist

- Heading hierarchy ชัดเจน (h1 > h2 > h3 ขนาดและ weight ต่างกันชัด)
- Body text อย่างน้อย 16px และ line-height ~1.5
- Line length อยู่ในช่วง 45-75 ตัวอักษร
- Font weights ไม่เกิน 3 ระดับใน app เดียว
- Number/data ใช้ tabular figures ใน table
- Truncation มี ellipsis และ tooltip/title สำหรับข้อความเต็ม
- Text ไม่ใช้สีจางเกินบน background
- Thai/English font pairing อ่านสบายทั้งสองภาษา

## Common Issues

- Heading levels ข้ามขั้น (h1 → h3) ทำ hierarchy พัง
- Text ยาวเต็มความกว้างจอบน desktop
- Font sizes ad-hoc หลายขนาดที่ต่างกันนิดเดียว
