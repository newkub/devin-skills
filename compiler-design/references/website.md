### Books

### "Compilers: Principles, Techniques, and Tools"
- **Authors**: Alfred V. Aho, Monica S. Lam, Ravi Sethi, Jeffrey D. Ullman
- **Description**: หนังสือ classic เรื่อง compiler design (Dragon Book)
- **Link**: https://suif.stanford.edu/dragonbook/

### "Modern Compiler Implementation in C"
- **Author**: Andrew W. Appel
- **Description**: Practical guide สำหรับ building compilers
- **Link**: https://www.cs.princeton.edu/~appel/modern/c/

### "Engineering a Compiler"
- **Authors**: Keith D. Cooper, Linda Torczon
- **Description**: Focus บน optimization และ code generation
- **Link**: https://www Elsevier.com/books/engineering-a-compiler/cooper/978-0-12-088478-0
