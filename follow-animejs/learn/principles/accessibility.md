# Accessibility

## Principle

Animations ควรเป็น accessible:
- **Respect Preferences** - respect user's motion preferences
- **Provide Controls** - ให้ controls สำหรับ pause/play
- **Focus Management** - manage focus ใน animations

## Application

- **prefers-reduced-motion** - ตรวจสอบ user preferences
- **Skip Links** - ให้ skip animations
- **ARIA Labels** - add ARIA labels สำหรับ animated elements
- **Keyboard Navigation** - รองรับ keyboard navigation
