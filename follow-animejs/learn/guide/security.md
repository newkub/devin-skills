# Security

## Security Considerations

- **XSS Prevention** - หลีกเลี่ยงการ inject HTML ผ่าน animations
- **Input Validation** - validate user input ก่อนใช้ใน animations
- **Sandboxing** - ใช้ sandboxing สำหรับ user-generated animations

## Best Practices

- **Sanitize Data** - sanitize data ก่อนใช้ใน animations
- **Limit Complexity** - จำกัดความซับซ้อนของ animations
- **Performance Limits** - จำกัด number ของ simultaneous animations
