# Migration

## Migrating from Anime.js v2 to v3

### Breaking Changes

- **API Changes** - ตรวจสอบ breaking changes ใน changelog
- **Plugin Updates** - update plugins สำหรับ v3
- **TypeScript** - อัปเดต types หากจำเป็น

### Migration Steps

1. Update package.json
2. Update imports
3. Update API calls
4. Test animations

## Migrating from GSAP

Anime.js API คล้ายกับ GSAP:
- **Timeline** - ใช้ timeline แทน GSAP timeline
- **Easing** - easing functions คล้ายกัน
- **Callbacks** - callback system คล้ายกัน
