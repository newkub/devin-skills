# Ecosystem

## Integrations

- **React** - ใช้กับ React components
- **Vue** - ใช้กับ Vue components
- **Angular** - ใช้กับ Angular components
- **Svelte** - ใช้กับ Svelte components

## Framework-Specific Libraries

- **react-animejs** - React wrapper สำหรับ Anime.js
- **vue-animejs** - Vue wrapper สำหรับ Anime.js
- **@animejs/vue** - Official Vue 3 plugin

## Tools

- **Anime.js Builder** - Build custom animations
- **Easing Functions** - Collection ของ easing functions
- **Plugins** - Community plugins
