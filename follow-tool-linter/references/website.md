# Tool Linter Official Resources

Skill นี้เป็น generic linter guide — ไม่มี package เดียวชื่อ `linter` (npm `linter` เป็น package เก่าที่ไม่เกี่ยวข้อง) — เลือกตัวจริงตาม tech stack:

## oxlint (TS/JS primary — fastest)

- [Website](https://oxc.rs)
- [Documentation](https://oxc.rs/docs/guide/usage/linter)
- [Repository](https://github.com/oxc-project/oxc)
- [Package Registry](https://www.npmjs.com/package/oxlint)

## Alternatives

- Biome (linter + formatter): https://biomejs.dev — https://github.com/biomejs/biome — `/follow-tool-biome`
- ESLint (largest ecosystem): https://eslint.org — https://github.com/eslint/eslint — `/follow-tool-eslint`
- clippy (Rust): https://doc.rust-lang.org/clippy/
- ruff (Python): https://docs.astral.sh/ruff/linter/
- golangci-lint (Go): https://golangci-lint.run — https://github.com/golangci/golangci-lint
