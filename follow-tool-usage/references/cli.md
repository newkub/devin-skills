# Usage CLI

## Install

```sh
bun add -D usage
```

## Version

- Latest on npm
- Repository: https://github.com/darkflare/usage
- Docs: https://github.com/darkflare/usage

## Commands

| commands | default | options |
|---|---|---||---|---|---||---|---|---||
| `usage` | Generate usage docs | --config, --input, --output, --format |
| `usage generate` | Generate from source | --input, --output |
| `usage --help` | Show help | (none) |

## Notes

Tooling may vary; verify with project docs.
