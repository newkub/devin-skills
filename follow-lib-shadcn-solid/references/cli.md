| Command | Description | Options |
|---------|-------------|---------|
| `bunx shadcn-solid@latest init` | Initialize `components.json`, install dependencies, add `cn` util, configure CSS variables | `-c, --cwd <path>` |
| `bunx shadcn-solid@latest add [components...]` | Copy component source into `src/components/ui/` (interactive pick if none given) | `-o, --overwrite`, `-a, --all`, `-c, --cwd` |
| `bunx shadcn-solid@latest diff [component]` | Check upstream updates against components | `-c, --cwd` |
