# Features

## Features หลักของ shadcn-solid

| Feature | คำอธิบาย |
|---------|-----------|
| **Component Registry** | Collection ของ accessible components |
| **Copy-Paste Workflow** | ไม่ต้องติดตั้งเป็น package แค่ copy-paste |
| **Full Customization** | เจ้าของ code ทั้งหมด สามารถแก้ไขได้ |
| **TypeScript Support** | Full type safety พร้อม IntelliSense |
| **Accessibility** | Built-in ARIA support จาก Kobalte |
| **Tailwind CSS** | Utility-first CSS พร้อม customization |
| **Dark Mode** | Built-in dark mode support |
| **Responsive** | Mobile-first responsive design |
| **SolidJS** | Fine-grained reactivity |
| **Open Source** | Free และ open source |

## Component Categories

| Category | Components |
|----------|------------|
| **Form** | Input, Button, Select, Checkbox, Radio, Switch, Slider, etc. |
| **Layout** | Card, Dialog, Sheet, Popover, Tooltip, etc. |
| **Navigation** | Tabs, Breadcrumb, Pagination, Menu, Navigation Menu, etc. |
| **Feedback** | Alert, Toast, Progress, Skeleton, etc. |
| **Data Display** | Table, Avatar, Badge, Calendar, etc. |
| **Typography** | Heading, Text, Label, etc. |

## Examples

shadcn-solid มี examples ที่พร้อมใช้:

| Example | คำอธิบาย |
|---------|-----------|
| **Mail** | Email application UI |
| **Cards** | Card layouts |
| **Authentication** | Login/signup forms |

## Advanced Features

| Feature | คำอธิบาย |
|---------|-----------|
| **Variants** | Multiple style variants ต่อ component |
| **Sizes** | Multiple size options |
| **Compound Components** | Composable component patterns |
| **Controlled/Uncontrolled** | รองรับทั้ง controlled และ uncontrolled modes |
| **Keyboard Navigation** | Full keyboard support |
| **Screen Reader** | ARIA labels และ announcements |
| **Focus Management** | Automatic focus trapping |
