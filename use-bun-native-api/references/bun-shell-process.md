# Bun Shell & Process APIs

| API | Description |
|-----|-------------|
| `$` | Shell template literal (`Bun.$`/`bun:shell`) for cross-platform commands — deep dive in `/use-bun-shell` |
| `Bun.spawn()` | Async child process, returns a `Subprocess`; stdin/stdout/stderr redirection and env vars |
| `Bun.spawnSync()` | Sync child process, returns a `SpawnSyncResult` |
