# Bun Hashing & Crypto APIs

Use Bun crypto APIs for security operations

- `Bun.password` - Password hashing (bcrypt, argon2, scrypt) with verification
- `Bun.hash()` - Fast hash function for general-purpose hashing
- `Bun.CryptoHasher()` - Streaming crypto hasher (SHA-1, SHA-256, SHA-512, MD5)
- `Bun.sha` - SHA hash utilities (sha-256, sha-384, sha-512, sha-512-256)
