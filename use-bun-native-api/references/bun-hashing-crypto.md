# Bun Hashing & Crypto APIs

| API | Description |
|-----|-------------|
| `Bun.hash()` | Fast non-cryptographic hash (wyhash) for general-purpose hashing |
| `Bun.CryptoHasher` | Streaming crypto hasher (SHA-1/256/384/512, MD5) |
| `Bun.password` | Password hashing and verification (bcrypt, argon2, scrypt) |
| `Bun.sha` | SHA utilities (sha-256, sha-384, sha-512, sha-512-256) |
