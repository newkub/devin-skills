# Bun Bundler & Build APIs

| API | Description |
|-----|-------------|
| `Bun.build()` | In-process bundler (JS/TS/CSS/HTML) with an esbuild-compatible API |
| `Bun.plugin()` | Register a build plugin with custom loaders |
| `Bun.Transpiler` | Transpile TypeScript/JSX/TSX to JavaScript |
| `Bun.FileSystemRouter` | File-based routing for frameworks (create with a root dir, match request paths) |
