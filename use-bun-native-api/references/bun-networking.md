# Bun Networking APIs

| API | Description |
|-----|-------------|
| `Bun.listen()` | TCP server (socket listener) |
| `Bun.connect()` | TCP client connection |
| `Bun.udpSocket()` | UDP socket with send/recv and multicast |
| `Bun.dns.lookup()` | DNS resolution with cache and prefetch |
| `fetch()` | Web-standard HTTP client (portable — see `references/bun-web-apis.md`) |
