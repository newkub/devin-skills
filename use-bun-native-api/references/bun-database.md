# Bun Database APIs

| API | Description |
|-----|-------------|
| `bun:sqlite` | Built-in SQLite driver (sync, high-performance queries, virtual tables) |
| `Bun.sql` / `Bun.SQL` | Postgres and MySQL client with tagged-template prepared statements |
| `Bun.redis` / `Bun.RedisClient` | Built-in Redis client (pipeline, pub/sub) |
| `S3Client` (from `"bun"`) | Built-in S3-compatible object storage client (upload, download, signed URLs) |
