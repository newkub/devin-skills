# Documentation Principles

หลักการสำหรับ documentation ด้วย Storybook

## Living Documentation

- Stories เป็น single source of truth
- Autodocs generate documentation อัตโนมัติ
- Keep documentation ใน sync กับ code
- Update docs เมื่อ component changes

## Documentation Structure

- Use autodocs สำหรับ component overview
- Add MDX สำหรับ detailed explanations
- Include usage examples ใน stories
- Document props และ variants

## Accessibility Documentation

- Document keyboard navigation
- Explain screen reader support
- Note accessibility considerations
- Include a11y test results

## Design System Integration

- Document design tokens
- Show component relationships
- Include usage guidelines
- Provide design rationale
