# Tool Template Starter API & Dependencies

## Install

```sh
bun add -D degit
```

## Version

- Latest: 3.10.0
- [Package Registry](https://www.npmjs.com/package/degit)
- [Repository](https://github.com/Rich-Harris/degit)

## Dependencies

- See package registry for transitive dependencies.

## Common API / Commands

| commands | description | default | options |
|---|---|---|---|
| `install` | Install degit in project | latest version | --save-dev, --save, --global |
| `degit` | Run the degit CLI | current workspace | --help, --version, --config |
| `configure` | Configure via config file | project defaults | --config, --file |
