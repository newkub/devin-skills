# review-gaps — Full Dimension Checklist

## 1. Collection Completeness

- [ ] findings จากทุก domain review รวมครบ
- [ ] coverage map: dimensions reviewed vs skipped + reason
- [ ] no domain ที่ควร review แต่ขาด

## 2. Deduplication

- [ ] same root cause merged, cross-domain overlaps linked
- [ ] contradictory findings resolved/escalated

## 3. Prioritization

- [ ] severity × impact × effort ordering
- [ ] dependency order between fixes
- [ ] quick wins separated from strategic items

## 4. Gap Analysis

- [ ] blind spots: areas no review covered
- [ ] systemic patterns across findings (root causes)
- [ ] risk of unfixed clusters

## 5. Actionability

- [ ] every finding has owner skill + fix path
- [ ] acceptance criteria per action
- [ ] realistic sequencing

## Scoring

- pass = 1, warning = 0.5, fail = 0; grade A (90+), B (80+), C (70+), D (60+), F (<60)
