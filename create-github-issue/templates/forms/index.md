# GitHub Issue Forms

Issue form templates (GitHub Forms YAML) for `.github/ISSUE_TEMPLATE/` — setup flow in `create-github-issue/references/issue-forms.md`

## Templates

- `bug_report.yml` — report a bug or unexpected behavior
- `feature_request.yml` — propose a feature or enhancement
- `plan.yml` — propose a plan, roadmap, or epic
- `test.yml` — request or report a test scenario
- `questions.yml` — ask a question or open a discussion
- `agents_task.yml` — create a task for an AI agent
- `config.yml` — configure blank issues and contact links

## Labels

Confirm the repo has these labels before deploying the templates:

- `bug`
- `feature`
- `plan`
- `test`
- `question`
- `agents-task`
