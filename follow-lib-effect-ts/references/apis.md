# Lib Effect Ts API & Dependencies

## Install

```sh
bun add -D effect
# or
npm install --save-dev effect
```

## Version

- Latest: 3.22.1
- [Package Registry](https://www.npmjs.com/package/effect)
- [Repository](https://github.com/Effect-TS/effect)

## Dependencies

- See package registry for transitive dependencies.

## Common API / Commands

| commands | description | default | options |
|---|---|---|---|
| `install` | Install effect in project | latest version | --save-dev, --save, --global |
| `import` | Import from 'effect' | default or named | (none) |
| `configure` | Configure project settings | project defaults | --config, --file |
| `use` | Use the main API / runtime | as documented | (none) |
| `import 'effect/HKT'` | Subpath export for HKT | entry as documented | (none) |
| `import 'effect/Ref'` | Subpath export for Ref | entry as documented | (none) |
| `import 'effect/STM'` | Subpath export for STM | entry as documented | (none) |
| `import 'effect/Cron'` | Subpath export for Cron | entry as documented | (none) |
| `import 'effect/Data'` | Subpath export for Data | entry as documented | (none) |
| `import 'effect/Exit'` | Subpath export for Exit | entry as documented | (none) |
| `import 'effect/Hash'` | Subpath export for Hash | entry as documented | (none) |
| `import 'effect/List'` | Subpath export for List | entry as documented | (none) |
| `import 'effect/Pool'` | Subpath export for Pool | entry as documented | (none) |
| `import 'effect/Sink'` | Subpath export for Sink | entry as documented | (none) |
