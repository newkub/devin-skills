# Lib Zaidian Ui API & Dependencies

## Install

```sh
bun add -D zaidian-ui
# or
npm install --save-dev zaidian-ui
```

## Version

- Latest: see registry

## Common API / Commands

| commands | description | default | options |
|---|---|---|---|
| `install` | Install zaidian-ui in project | latest version | --save-dev, --save, --global |
| `import` | Import from 'zaidian-ui' | default or named | (none) |
| `configure` | Configure project settings | project defaults | --config, --file |
| `use` | Use the main API / runtime | as documented | (none) |
