## Goal

ใช้ Zaidian UI สำหรับ UI components สำหรับ SolidJS ด้วย accessible, customizable components ที่ built with Kobalte, Corvu, และ Tailwind CSS

## Scope

ใช้สำหรับสร้าง UI components ด้วย Zaidan UI registry บน SolidJS

## Execute

### 1. Install And Setup

> Goal: ติดตั้ง Zaidian UI สำหรับ SolidJS

1. ติดตั้ง Zaidian UI สำหรับ SolidJS
2. อ่าน `guide/installation.md` สำหรับการติดตั้งและ setup
3. อ่าน `guide/quick-start.md` สำหรับเริ่มต้นใช้งาน

### 2. Learn Key Concepts

> Goal: เข้าใจแนวคิดหลัก

1. อ่าน `guide/key-concept.md` สำหรับแนวคิดหลัก
2. อ่าน `guide/how-it-works.md` สำหรับวิธีการทำงาน
3. อ่าน `key-concepts/` สำหรับแนวคิดเฉพาะทาง

### 3. Use Registry And Configure

> Goal: ใช้ registry และตั้งค่า

1. ใช้ registry สำหรับ add components
2. อ่าน `guide/configuration.md` สำหรับการตั้งค่า
3. อ่าน `references/configuration.md` สำหรับ configuration reference

### 4. Customize And Apply Best Practices

> Goal: customize components ตาม best practices

1. Customize components ตามความต้องการ
2. อ่าน `guide/best-practices.md` สำหรับ best practices
3. อ่าน `principles/` สำหรับหลักการ
4. ใช้ accessible components

### 5. Integrate With SolidJS

> Goal: integrate กับ SolidJS

1. อ่าน `guide/integration.md` สำหรับ SolidJS integration
2. อ่าน `guide/architecture.md` สำหรับ system architecture
3. อ่าน `guide/structure.md` สำหรับ project structure

### 6. Troubleshoot

> Goal: แก้ปัญหาทั่วไป

1. อ่าน `guide/troubleshooting.md` สำหรับปัญหาทั่วไป

## Rules

- ใช้ registry สำหรับ add components
- ใช้ copy-to-own pattern เสมอ
- ใช้ Kobalte และ Corvu สำหรับ accessible primitives
- ใช้ Tailwind CSS สำหรับ styling
- ใช้ backticks สำหรับ commands, components
- ใช้ code blocks สำหรับ component examples
- ใช้ ansi markdown diagrams สำหรับ flow และ architecture
- ใช้ accessible components เสมอ
- Customize components ตามความต้องการ

## Expected Outcome

- UI components ที่ accessible และ customizable
- Code ที่ copy-to-own และ maintainable
- Integration ที่ smooth กับ SolidJS
- Components ที่ follow accessibility best practices
