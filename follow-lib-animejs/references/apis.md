# Lib Animejs API & Dependencies

## Install

```sh
bun add -D animejs
# or
npm install --save-dev animejs
```

## Version

- Latest: 4.5.0
- [Package Registry](https://www.npmjs.com/package/animejs)
- [Repository](https://github.com/juliangarnier/anime)

## Dependencies

- See package registry for transitive dependencies.

## Common API / Commands

| commands | description | default | options |
|---|---|---|---|
| `install` | Install animejs in project | latest version | --save-dev, --save, --global |
| `import` | Import from 'animejs' | default or named | (none) |
| `configure` | Configure project settings | project defaults | --config, --file |
| `use` | Use the main API / runtime | as documented | (none) |
| `import 'animejs/svg'` | Subpath export for svg | entry as documented | (none) |
| `import 'animejs/text'` | Subpath export for text | entry as documented | (none) |
| `import 'animejs/scope'` | Subpath export for scope | entry as documented | (none) |
| `import 'animejs/timer'` | Subpath export for timer | entry as documented | (none) |
| `import 'animejs/utils'` | Subpath export for utils | entry as documented | (none) |
| `import 'animejs/waapi'` | Subpath export for waapi | entry as documented | (none) |
| `import 'animejs/engine'` | Subpath export for engine | entry as documented | (none) |
| `import 'animejs/events'` | Subpath export for events | entry as documented | (none) |
| `import 'animejs/layout'` | Subpath export for layout | entry as documented | (none) |
| `import 'animejs/easings'` | Subpath export for easings | entry as documented | (none) |
