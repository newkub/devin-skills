# CLI Commands

Command-line interface สำหรับ Dioxus development

## Cargo Commands

| Command | Description |
|---------|-------------|
| `dx build` | Build for web/desktop |
| `dx serve` | Start dev server with hot reload |
| `dx config` | Manage configuration |
| `dx create` | Create new project |
| `dx bundle` | Create distribution bundle |

## Web Development

| Command | Description |
|---------|-------------|
| `dx serve --platform web` | Start web dev server |
| `dx build --platform web` | Build web app |
| `dx bundle --platform desktop` | Bundle desktop app |

## Options

| Flag | Description |
|------|-------------|
| `--platform` | Target platform (web/desktop) |
| `--hot-reload` | Enable hot reload |
| `--port` | Set port number |
