# CLI Reference - Node.js

## node

```bash
node file.js              # Run file
node --version            # Show version
node --watch file.js      # Watch mode
node --inspect file.js    # Debug mode
```

## bun

```bash
bun init                   # Initialize project
bun install                # Install deps
bun install <pkg>          # Add package
bun install -D <pkg>       # Dev dependency
bun test                   # Run tests
bun run <script>           # Run script
```

## bunx

```bash
bunx prettier .
bunx create-react-app
```

## Core Commands

| Command | Description |
|---------|-------------|
| `node -v` | Version |
| `bun -v` | bun Version |
| `bun init -y` | Quick init |
| `bun install` | Install deps |
