# All Features

## Computation Features

| Feature | คำอธิบาย | การใช้งาน |
|---------|-----------|-----------|
| Time Complexity | วิเคราะห์เวลาที่ใช้ | ประเมินประสิทธิภาพ |
| Space Complexity | วิเคราะห์หน่วยความจำ | ประเมินการใช้หน่วยความจำ |
| Big O Notation | สัญลักษณ์แสดงความซับซ้อน | เปรียบเทียบอัลกอริทึม |
| Recursion | การเรียกตัวเองซ้ำ | แก้ปัญหาแบบ divide and conquer |
| Memoization | เก็บผลลัพธ์ที่คำนวณแล้ว | ลดการคำนวณซ้ำ |

## Discrete Math Features

| Feature | คำอธิบาย | การใช้งาน |
|---------|-----------|-----------|
| Boolean Logic | ตรรกศาสตร์บูลีน | การตัดสินใจแบบ binary |
| Graph Traversal | การสำรวจกราฟ | BFS, DFS |
| Combinatorics | การจัดหมู่ | การนำไปใช้ใน algorithm |
| Probability | ความน่าจะเป็น | การวิเคราะห์ความเป็นไปได้ |
| Number Theory | ทฤษฎีจำนวน | การเข้ารหัส |

## Information Theory Features

| Feature | คำอธิบาย | การใช้งาน |
|---------|-----------|-----------|
| Entropy | การวัดความไม่แน่นอน | การบีบอัดข้อมูล |
| Huffman Coding | การเข้ารหัส Huffman | Lossless compression |
| Shannon's Theorem | ทฤษฎีของ Shannon | ขีดจำกัดของการส่งข้อมูล |
| Error Correction | การแก้ไขข้อผิดพลาด | การส่งข้อมูลที่เชื่อถือได้ |

## Linear Algebra Features

| Feature | คำอธิบาย | การใช้งาน |
|---------|-----------|-----------|
| Vector Operations | การดำเนินการเวกเตอร์ | การคำนวณใน ML |
| Matrix Multiplication | การคูณเมทริกซ์ | Neural networks |
| Eigen Decomposition | การแยกค่าเฉพาะ | PCA, spectral analysis |
| Linear Systems | ระบบสมการเชิงเส้น | การแก้สมการ |

## Set Theory Features

| Feature | คำอธิบาย | การใช้งาน |
|---------|-----------|-----------|
| Set Operations | การดำเนินการเซต | การจัดการข้อมูล |
| Venn Diagrams | แผนภาพเวนน์ | การแสดงความสัมพันธ์ |
| Power Sets | เซตกำลัง | การวิเคราะห์ความเป็นไปได้ |
| Cardinality | จำนวนสมาชิก | การเปรียบเทียบขนาดเซต |
