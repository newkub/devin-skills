# Configuration

## ไม่มีการตั้งค่า

คณิตศาสตร์เป็นความรู้พื้นฐาน ไม่ต้องการ configuration

## การตั้งค่า Libraries

ถ้าใช้ libraries คณิตศาสตร์:

### Python NumPy

```python
import numpy as np
# ไม่ต้อง config พิเศษ
```

### JavaScript math.js

```javascript
import { create, all } from 'mathjs'
const math = create(all)
// ไม่ต้อง config พิเศษ
```

### Rust nalgebra

```rust
use nalgebra as na;
// ไม่ต้อง config พิเศษ
```
