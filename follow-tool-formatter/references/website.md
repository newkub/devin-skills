# Tool Formatter Official Resources

## Prettier (TS/JS primary)

- [Website](https://prettier.io)
- [Documentation](https://prettier.io/docs/)
- [Repository](https://github.com/prettier/prettier)
- [Package Registry](https://www.npmjs.com/package/prettier)

## Alternatives

- Biome (formatter + linter): https://biomejs.dev — https://github.com/biomejs/biome — `/follow-tool-biome`
- dprint (pluggable multi-language): https://dprint.dev — https://github.com/dprint/dprint — `/follow-tool-dprint`
- rustfmt (Rust): https://github.com/rust-lang/rustfmt
- ruff format (Python): https://docs.astral.sh/ruff/formatter/
- gofmt (Go): https://pkg.go.dev/cmd/gofmt
