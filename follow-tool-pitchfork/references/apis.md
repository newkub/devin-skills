# Tool Pitchfork API & Dependencies

## Install

```sh
bun add -D pitchfork
# or
npm install --save-dev pitchfork
```

## Version

- Latest: 0.0.16
- [Package Registry](https://www.npmjs.com/package/pitchfork)
- [Repository](https://github.com/omardelarosa/pitchfork-npm)

## Dependencies

- See package registry for transitive dependencies.

## Common API / Commands

| commands | description | default | options |
|---|---|---|---|
| `install` | Install pitchfork in project | latest version | --save-dev, --save, --global |
| `pitchfork` | Run the pitchfork CLI | current workspace | --help, --version, --config |
| `configure` | Configure via config file | project defaults | --config, --file |
