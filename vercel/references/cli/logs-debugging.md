# Logs & Debugging

## vercel logs

View deployment logs.

```bash
vercel logs [deployment-url]
```

| Option | Description |
|--------|-------------|
| `--follow` | Follow log stream |
| `--since` | Start time |
| `--until` | End time |
| `--limit` | Number of logs |

## vercel inspect

Inspect deployment details.

```bash
vercel inspect [deployment-url]
```
