# Deployment Features

## 1. Instant Deployments

```bash
# Deploy with single command
vercel

# Deploy to production
vercel --prod
```

## 2. Preview Deployments

```text
Every PR automatically gets:
- Unique preview URL
- Deployment status checks
- Shareable link
```

## 3. Git Integration

```bash
# Automatic on push
git push origin main

# Or manual
vercel --prod
```
