# Check Frontmatter Related

## Goal

ตรวจ `related` ใน frontmatter

## Checks

1. อ่าน `SKILL.md` แต่ละ skill
2. ดึง `related` list
3. ตรวจว่าแต่ละ `related` skill มีอยู่จริง
4. ระบุ `related` ทีชี้ไปยัง skill ทีไม่มีอยู่
