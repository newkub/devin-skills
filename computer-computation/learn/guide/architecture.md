## Lambda Calculus Architecture

```text
┌─────────────────────────────────────────────────────────────────┐
│                 Lambda Calculus Architecture                      │
├─────────────────────────────────────────────────────────────────┤
│                                                                   │
│   Syntax:                                                        │
│   ┌─────────────────────────────────────────────────────────┐ │
│   │  Term ::= Variable                                          │ │
│   │         | λ Variable . Term                                 │ │
│   │         | ( Term Term )                                    │ │
│   │                                                          │ │
│   │  x, y, z      : Variables                                  │ │
│   │  λx.M         : Abstraction (function)                      │ │
│   │  M N          : Application (call)                         │ │
│   └─────────────────────────────────────────────────────────┘ │
│                                                                   │
│   Reduction Rules:                                               │
│   ┌─────────────────────────────────────────────────────────┐  │
│   │  α-conversion:    λx.M = λy.M[x/y]  (if y ∉ FV(M))    │  │
│   │  β-reduction:      (λx.M)N → M[x/N]                     │  │
│   │  η-reduction:     λx.Mx = M        (if x ∉ FV(M))     │  │
│   └─────────────────────────────────────────────────────────┘ │
│                                                                   │
│   Church Encodings:                                              │
│   ┌─────────────────────────────────────────────────────────┐  │
│   │  True  = λt.λf.t                                        │  │
│   │  False = λt.λf.f                                        │  │
│   │  If    = λb.λt.λf.b t f                                  │  │
│   │  0     = λf.λx.x                                         │  │
│   │  succ  = λn.λf.λx.f (n f x)                              │  │
│   └─────────────────────────────────────────────────────────┘ │
│                                                                   │
└─────────────────────────────────────────────────────────────────┘
```
