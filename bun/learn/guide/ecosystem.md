# Ecosystem

## Core Tools

### Bun CLI

- `bun run` - รัน scripts
- `bun install` - ติดตั้ง dependencies
- `bun build` - bundle code
- `bun test` - รัน tests
- `bun create` - สร้างโปรเจกต์ใหม่

### Bun APIs

- `Bun.file()` - File I/O
- `Bun.serve()` - HTTP server
- `Bun.write()` - Write files
- `Bun.passwordHash()` - Password hashing

## Supported Frameworks

### Web Frameworks

- Hono - Fast web framework
- Elysia - Ergonomic web framework
- Bun.serve() - Native HTTP server

### Full-stack Frameworks

- Next.js - รองรับ Bun runtime
- Nuxt - รองรับ Bun runtime
- SvelteKit - รองรับ Bun runtime

## Popular Libraries

### Database

- Drizzle ORM - TypeScript ORM
- Prisma - Database toolkit
- Postgres.js - PostgreSQL client

### Testing

- Bun Test - Built-in test runner
- Vitest - Unit testing framework

### Utilities

- Zod - Schema validation
- Effect-TS - Functional programming
- UnoCSS - Atomic CSS

## Package Manager Compatibility

Bun รองรับ `package.json` และสามารถใช้กับ bun packages, Yarn workspaces, และ bun workspaces

## Build Tools

- Vite - รองรับ Bun
- esbuild - รองรับ Bun
- Rollup - รองรับผ่าน plugins

## CI/CD

Bun รองรับใน GitHub Actions, GitLab CI, CircleCI, และ Vercel
