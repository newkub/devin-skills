## Built-in Objects

### Global Objects

| Object | Description |
|--------|-------------|
| `Object` | Base object for all objects |
| `Array` | Array operations and methods |
| `String` | String manipulation |
| `Number` | Number operations and constants |
| `Boolean` | Boolean object wrapper |
| `Symbol` | Unique identifiers |
| `BigInt` | Arbitrary precision integers |
| `Function` | Function object |
| `Date` | Date and time operations |
| `RegExp` | Regular expressions |
| `Error` | Error handling |
| `Promise` | Asynchronous operations |
| `Map` | Key-value pairs with any keys |
| `Set` | Unique values collection |
| `WeakMap` | Weak key-value pairs |
| `WeakSet` | Weak unique values |
| `Proxy` | Object interception |
| `Reflect` | Reflective operations |
| `Intl` | Internationalization |
| `JSON` | JSON parsing and stringification |

| Function | Description |
|----------|-------------|
| `eval()` | Evaluate JavaScript code |
| `parseInt()` | Parse string to integer |
| `parseFloat()` | Parse string to float |
| `isNaN()` | Check if value is NaN |
| `isFinite()` | Check if value is finite |
| `decodeURI()` | Decode URI |
| `decodeURIComponent()` | Decode URI component |
| `encodeURI()` | Encode URI |
| `encodeURIComponent()` | Encode URI component |
