- Automated testing
- Automated building
- Automated deployment
- Multi-environment support

- Push/PR events
- Scheduled workflows
- Manual dispatch
- External events

- Parallel execution
- Job dependencies

- Dependency caching

- Encrypted secrets
- Environment secrets
- Organization secrets

### Reusable Workflows

- Share workflows ระหว่าง repositories
- Pass inputs และ outputs
- Version control

### Self-hosted Runners

- Custom runners
- On-premise execution
- Specific hardware requirements

### Marketplace

- Thousands of actions
- Community contributions
- Verified creators
