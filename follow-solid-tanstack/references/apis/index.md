# Solid Tanstack API & Dependencies

## Install

```sh
bun add -D @tanstack/solid-query
# or
npm install --save-dev @tanstack/solid-query
```

## Version

- Latest: 5.102.8
- [Package Registry](https://www.npmjs.com/package/@tanstack/solid-query)
- [Repository](https://github.com/TanStack/query)

## Dependencies

- See package registry for transitive dependencies.

## Common API / Commands

| commands | description | default | options |
|---|---|---|---|
| `install` | Install @tanstack/solid-query in project | latest version | --save-dev, --save, --global |
| `import` | Import from '@tanstack/solid-query' | default or named | (none) |
| `configure` | Configure project settings | project defaults | --config, --file |
| `use` | Use the main API / runtime | as documented | (none) |
| `import '@tanstack/solid-queryimport'` | Subpath export for import | entry as documented | (none) |
| `import '@tanstack/solid-queryrequire'` | Subpath export for require | entry as documented | (none) |
| `import '@tanstack/solid-querydevelopment'` | Subpath export for development | entry as documented | (none) |
| `import '@tanstack/solid-query@tanstack/custom-condition'` | Subpath export for @tanstack/custom-condition | entry as documented | (none) |
