# How It Works

## Vue Reactivity System

Vue ใช้ reactive system ที่ทำให้การเปลี่ยนแปลงข้อมูลสะท้อนใน UI อัตโนมัติ

```
┌─────────────────────────────────────────────────────────┐
│                    Vue Application                       │
├─────────────────────────────────────────────────────────┤
│                                                          │
│  ┌──────────────┐    ┌──────────────┐    ┌──────────┐ │
│  │    Data      │───▶│  Reactive    │───▶│    UI     │ │
│  │   (State)    │    │   System     │    │   (DOM)   │ │
│  └──────────────┘    └──────────────┘    └──────────┘ │
│        ▲                                      │        │
│        │                                      │        │
│        └───────────── Watchers ───────────────┘        │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

## Virtual DOM Diffing

```
┌─────────────────────────────────────────────────────────┐
│                 Virtual DOM Process                      │
├─────────────────────────────────────────────────────────┤
│                                                          │
│  State Change ──▶ Re-render ──▶ Diff ──▶ Update DOM     │
│       │              │           │         │            │
│       ▼              ▼           ▼         ▼            │
│  ┌─────────┐    ┌─────────┐  ┌───────┐ ┌──────────┐   │
│  │ Before  │    │ After  │  │ Patch │ │   Real   │   │
│  │  VNode  │    │  VNode │  │ Tree  │ │    DOM   │   │
│  └─────────┘    └─────────┘  └───────┘ └──────────┘   │
│                                                          │
└─────────────────────────────────────────────────────────┘
```
