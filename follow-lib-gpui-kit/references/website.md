## Description

GPUI Kit — comprehensive Rust framework for building high-performance desktop apps with GPUI (UI framework from Zed Industries). Developed by Longbridge. Sections: Docs (GPUI guides), Component catalog, Base, Shell, App Stories, Design Guides, Coding Guides.

## Doc Sections

- **GPUI Kit guides**: Installation, Getting Started, Entity, Context, Window, Multi Window, ElementId, Focus, SharedString, Render, RenderOnce, Style, Action, KeyBinding, Event, Task, Global, View Cache, Element, Paint, TextSystem, Geometry, Animation, Testing, Accessibility, WebAssembly, Images, Icons & Assets, Fonts, I18N, SystemNotification, Native Extensions, WebView, Mobile, Packaging, Auto Update, FPS Monitor
- **Component**: ~75 components ดู [components.md](components.md)
- **Base**: primitives พื้นฐาน
- **Shell**: app shell
- **App Stories**: full app recipes
