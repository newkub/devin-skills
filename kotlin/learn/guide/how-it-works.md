# How It Works

## Kotlin Compiler Architecture

```
┌─────────────────────────────────────────────────────────────┐
│                    Kotlin Compiler (kotlinc)                 │
├─────────────────────────────────────────────────────────────┤
│  1. Lexer/Scanner      →  Token Stream                       │
│  2. Parser             →  AST (Abstract Syntax Tree)         │
│  3. Resolver           →  Resolved AST (Symbols)             │
│  4. Type Checking      →  Type-checked AST                   │
│  5. IR Builder         →  Kotlin IR (Intermediate Rep)       │
│  6. Backend            →  Bytecode / JS / Native            │
└─────────────────────────────────────────────────────────────┘
```

## Compilation Targets

```
┌─────────────────────────────────────────────────────────────┐
│                    Kotlin Targets                           │
├─────────────────────────────────────────────────────────────┤
│  JVM Bytecode    →  .class files (default)                 │
│  JavaScript      →  .js files (Kotlin/JS)                 │
│  Native          →  Native binaries (LLVM)                │
└─────────────────────────────────────────────────────────────┘
```

## Kotlin to Bytecode

```kotlin
// Kotlin source
class User(val name: String) {
    fun greet() = "Hello, $name"
}
```

Compiles to equivalent Java bytecode:

```java
// Generated Bytecode (simplified)
public final class User {
    private final String name;
    
    public User(String name) {
        this.name = name;
    }
    
    public final String getName() { return this.name; }
    
    public final String greet() { return "Hello, " + this.name; }
}
```

## Null Safety Flow

```
┌─────────────────────────────────────────────────────────────┐
│                   Null Safety System                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   var name: String? = null     // Nullable type             │
│   var nonNull: String = "hi"   // Non-null type             │
│                                                             │
│   // Safe call operator                                    │
│   name?.length                 // Returns Int? (nullable)   │
│                                                             │
│   // Elvis operator                                        │
│   val len = name?.length ?: 0  // Default if null           │
│                                                             │
│   // Not-null assertion (use carefully)                    │
│   name!!.length               // Throws if null             │
└─────────────────────────────────────────────────────────────┘
```

## Coroutines Flow

```
┌─────────────────────────────────────────────────────────────┐
│                   Coroutines Flow                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   suspend fun fetchData(): String = suspendCoroutine {       │
│       // Long-running operation                              │
│       continuation.resume("data")                            │
│   }                                                          │
│                                                             │
│   // Scope & Dispatcher                                      │
│   CoroutineScope(Dispatchers.IO).launch {                    │
│       val result = fetchData()                               │
│       withContext(Dispatchers.Main) {                        │
│           updateUI(result)                                   │
│       }                                                      │
│   }                                                          │
└─────────────────────────────────────────────────────────────┘
```

## Smart Casts

```kotlin
fun process(obj: Any) {
    // Compiler tracks type narrowing
    if (obj is String) {
        // obj is automatically cast to String here
        println(obj.length)  // No explicit cast needed
    }
    
    when (obj) {
        is Int -> println(obj * 2)      // Smart cast to Int
        is String -> println(obj.uppercase()) // Smart cast to String
        is List<*> -> println(obj.size)  // Smart cast to List
    }
}
```
