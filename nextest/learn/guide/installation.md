## Installation Methods

### 1. Pre-built Binaries (Recommended)

```bash
cargo install cargo-nextest
```

### 2. From Source

```bash
cargo install cargo-nextest --git https://github.com/nextest-rs/nextest
```

### 3. Package Managers

#### Homebrew (macOS)

```bash
brew install cargo-nextest
```

#### Arch Linux

```bash
pacman -S cargo-nextest
```

## Verification

```bash
cargo nextest --version
```

## Requirements

- Rust 1.70+ หรือใหม่กว่า
- cargo ที่เป็นปัจจุบัน
