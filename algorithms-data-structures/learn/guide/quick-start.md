# Quick Start

## เริ่มต้นเรียน Algorithms อย่างรวดเร็ว

### Step 1: สร้าง Project Structure

```bash
mkdir algorithms-demo
cd algorithms-demo
mkdir src tests
```

### Step 2: สร้าง Sorting Algorithms

**src/sorting.py**:
```	ypescript\n// TypeScript/Bun example\n```

### Step 3: สร้าง Searching Algorithms

**src/searching.py**:
```	ypescript\n// TypeScript/Bun example\n```

### Step 4: สร้าง Data Structures

**src/data_structures.py**:
```	ypescript\n// TypeScript/Bun example\n```

### Step 5: สร้าง Main Program

**src/main.py**:
```	ypescript\n// TypeScript/Bun example\n```

### Step 6: สร้าง Tests

**tests/test_algorithms.py**:
```	ypescript\n// TypeScript/Bun example\n```

### Step 7: Build และ Run

```bash
# Run main program
python src/main.py

# Run tests
pytest tests/

# Run with coverage
pytest tests/ --cov=src --cov-report=html
```

### Step 8: Benchmark

**src/benchmark.py**:
```	ypescript\n// TypeScript/Bun example\n```
