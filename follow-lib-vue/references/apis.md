# Lib Vue API & Dependencies

## Install

```sh
bun add -D vue
# or
npm install --save-dev vue
```

## Version

- Latest: 3.5.42
- [Package Registry](https://www.npmjs.com/package/vue)
- [Repository](https://github.com/vuejs/core)

## Dependencies

- See package registry for transitive dependencies.

## Common API / Commands

| commands | description | default | options |
|---|---|---|---|
| `install` | Install vue in project | latest version | --save-dev, --save, --global |
| `import` | Import from 'vue' | default or named | (none) |
| `configure` | Configure project settings | project defaults | --config, --file |
| `use` | Use the main API / runtime | as documented | (none) |
| `import 'vue/jsx'` | Subpath export for jsx | entry as documented | (none) |
| `import 'vue/dist/*'` | Subpath export for dist/* | entry as documented | (none) |
| `import 'vue/jsx-runtime'` | Subpath export for jsx-runtime | entry as documented | (none) |
| `import 'vue/compiler-sfc'` | Subpath export for compiler-sfc | entry as documented | (none) |
| `import 'vue/jsx-dev-runtime'` | Subpath export for jsx-dev-runtime | entry as documented | (none) |
| `import 'vue/server-renderer'` | Subpath export for server-renderer | entry as documented | (none) |
