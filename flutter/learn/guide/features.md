# Features

## ฟีเจอร์หลักของ Flutter

## Cross-Platform Support

| Platform | Status | Notes |
|----------|--------|-------|
| **iOS** | ✅ Full support | iOS 12+ |
| **Android** | ✅ Full support | Android 5.0+ (API 21+) |
| **Web** | ✅ Full support | Chrome, Firefox, Safari, Edge |
| **Windows** | ✅ Stable | Windows 10+ |
| **macOS** | ✅ Stable | macOS 10.14+ |
| **Linux** | ✅ Stable | Debian, Ubuntu, etc. |

## Key Features

| Feature | Description |
|---------|-------------|
| **Hot Reload** | เห็นการเปลี่ยนแปลงทันทีโดยไม่ต้อง restart |
| **Native Performance** | Compile เป็น native code ไม่ใช่ WebView |
| **Rich Widgets** | Material Design & Cupertino widgets พร้อมใช้ |
| **State Management** | หลายวิธีจัดการ state (Provider, BLoC, Riverpod) |
| **Access to Native APIs** | Platform channels สำหรับเข้าถึง native features |
| **Internationalization** | Built-in i18n support |
| **Testing** | Unit, widget, integration testing พร้อมใช้ |

## Development Tools

| Tool | Description |
|------|-------------|
| **Flutter CLI** | Command-line tools สำหรับ build, run, test |
| **Dart DevTools** | Debugging, profiling, inspection |
| **VS Code / Android Studio** | IDE plugins พร้อมใช้ |
| **Flutter Inspector** | Widget tree inspection |

## Performance Features

- **60 FPS** on mobile devices
- **120 FPS** on high-refresh-rate displays
- **Skia Graphics Engine** สำหรับ rendering ที่รวดเร็ว
- **AOT Compilation** สำหรับ production builds
- **Tree Shaking** ลดขนาด app
