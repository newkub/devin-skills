# review-writing — Full Dimension Checklist

## 1. Writing Quality

- [ ] clear, concise, correct grammar/spelling
- [ ] tone consistent, active voice
- [ ] terminology glossary consistent
- [ ] scannable: headings, lists, short paragraphs

## 2. Naming Conventions

- [ ] identifiers, files, docs names consistent
- [ ] no ambiguous jargon, defined terms used consistently

## 3. Discoverability

- [ ] searchable: keywords, titles descriptive
- [ ] cross-links between related content
- [ ] index/TOC/nav coverage

## 4. Accuracy

- [ ] content matches current behavior/code
- [ ] examples tested, commands verified
- [ ] version-specific info marked

## 5. Audience Fit

- [ ] reading level matches audience
- [ ] prerequisite knowledge stated
- [ ] progressive disclosure (simple → advanced)

## Scoring

- pass = 1, warning = 0.5, fail = 0; grade A (90+), B (80+), C (70+), D (60+), F (<60)
