# Score

## Goal

ให้คะแนน readability ต่อ file หรือ section

## Checks

1. ให้คะแนน 0-100 ต่อ file/section
2. ระบุ grade: A (90+), B (80+), C (70+), D (60+), F (<60)
3. ระบุจุดทีทำให้คะแนนลด
4. เปรียบเทียบ before/after ถ้ามี
