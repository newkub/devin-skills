# SQL-like Syntax

## Principle

Drizzle ใช้ syntax คล้าย SQL:
- **Familiar Syntax** - syntax คล้าย SQL
- **Low Learning Curve** - เรียนรู้ง่าย
- **SQL Power** - มี power เหมือน SQL

## Application

- **Use SQL Patterns** - ใช้ patterns คล้าย SQL
- **Compose Queries** - compose queries แบบ SQL
- **Understand SQL** - เข้าใจ SQL จะช่วยใช้ Drizzle
