# Type Safety

## Principle

Drizzle ออกแบบมาเพื่อ type safety:
- **Compile-time Checks** - TypeScript checks ที่ compile-time
- **Type Inference** - automatic type inference
- **Schema-to-Type** - types จาก schema definitions

## Application

- **Use Schema Types** - ใช้ types จาก schema
- **Avoid Any** - หลีกเลี่ยง `any` types
- **Type Guards** - ใช้ type guards สำหรับ runtime checks
