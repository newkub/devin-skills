# Security

## Security Considerations

- **SQL Injection** - Drizzle ป้องกัน SQL injection อัตโนมัติ
- **Parameterized Queries** - ใช้ parameterized queries เสมอ
- **Environment Variables** - ใช้ env vars สำหรับ database credentials
- **Encryption** - encrypt sensitive data

## Best Practices

- **Validate Input** - validate input ก่อน insert
- **Use Prepared Statements** - Drizzle ใช้ prepared statements อัตโนมัติ
- **Limit Access** - limit database access permissions
- **Audit Logs** - log database operations
