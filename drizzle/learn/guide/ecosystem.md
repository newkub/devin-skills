# Ecosystem

## Integrations

- **PostgreSQL** - Full support สำหรับ PostgreSQL
- **MySQL** - Full support สำหรับ MySQL
- **SQLite** - Full support สำหรับ SQLite
- **PlanetScale** - Serverless MySQL support
- **Neon** - Serverless PostgreSQL support

## Tools

- **Drizzle Kit** - CLI tool สำหรับ migrations
- **Drizzle Studio** - GUI สำหรับ database management
- **Drizzle ORM** - Core ORM library
