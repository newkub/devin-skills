# Troubleshooting

## Common Issues

### Connection Errors

- **Connection String** - ตรวจสอบ connection string
- **Database URL** - ตรวจสอบ database URL
- **Network** - ตรวจสอบ network connectivity

### Migration Errors

- **Schema Mismatch** - ตรวจสอบ schema ตรงกับ database
- **Migration Conflicts** - resolve migration conflicts
- **Rollback** - ใช้ rollback เมื่อ migration ล้มเหลว

### Type Errors

- **Type Inference** - ตรวจสอบ type inference
- **Schema Types** - ตรวจสอบ schema types
- **Generic Types** - ใช้ generic types อย่างถูกต้อง
