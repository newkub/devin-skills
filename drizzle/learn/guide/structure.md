# Structure

## Project Structure

```
my-drizzle-app/
├── drizzle/
│   ├── schema.ts
│   ├── queries.ts
│   └── migrations/
├── src/
│   ├── db.ts
│   └── models/
└── drizzle.config.ts
```

## File Organization

- **drizzle/** - Drizzle ORM files
- **schema.ts** - Database schema definitions
- **queries.ts** - Query builders
- **migrations/** - Migration files
- **db.ts** - Database connection
- **drizzle.config.ts** - Drizzle configuration
