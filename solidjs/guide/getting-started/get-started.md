## เริ่มต้นเรียนรู้ SolidJS

SolidJS เป็น JavaScript framework ที่ใช้ reactive programming โดยไม่ต้องใช้ Virtual DOM ทำให้มี performance สูงและขนาดเล็ก

### ทำไมต้อง SolidJS

- **Performance สูง** - ไม่ใช้ Virtual DOM ทำให้เร็วกว่า React
- **ขนาดเล็ก** - Bundle size เล็กมาก
- **Reactive** - ใช้ fine-grained reactivity
- **TypeScript support** - รองรับ TypeScript เต็มรูปแบบ
- **Simple API** - API ง่ายต่อการเรียนรู้
