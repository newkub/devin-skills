## Getting Started

เริ่มต้นเรียนรู้ SolidJS ตั้งแต่การติดตั้งจนถึงการสร้างโปรเจกต์แรก

## Topics

### [Get Started](./get-started.md)
- ภาพรวม SolidJS
- ทำไมต้อง SolidJS
- เส้นทางการเรียนรู้
- แหล่งเรียนรู้เพิ่มเติม

### [Installation](./installation.md)
- ติดตั้งด้วย Bun, bun, bun, yarn
- ติดตั้ง TypeScript support
- ติดตั้ง Babel preset
- ติดตั้ง SolidStart
- ติดตั้ง packages เพิ่มเติม
- การตั้งค่า Vite และ Babel

### [Quick Start](./quick-start.md)
- สร้าง Component แรก
- ทำความเข้าใจ Signals
- การ Render ใน DOM
- การใช้ JSX
- การใช้ Control Flow
- การใช้ Effects
- การใช้ Memos

### [First Project](./first-project.md)
- สร้างโปรเจกต์ด้วย create-solid
- เลือก options
- โครงสร้างโปรเจกต์
- สร้าง Counter Component
- ใช้ Control Flow
- ใช้ List Rendering
- ใช้ Effects
- ใช้ Memos
- ใช้ Stores
- รัน Development Server
- Build สำหรับ Production

## Learning Path

1. เริ่มจาก [Get Started](./get-started.md) เพื่อเข้าใจภาพรวม
2. ติดตั้งด้วย [Installation](./installation.md)
3. เรียนรู้พื้นฐานด้วย [Quick Start](./quick-start.md)
4. สร้างโปรเจกต์แรกด้วย [First Project](./first-project.md)
5. ศึกษา key-concepts ในโฟลเดอร์ `../key-concepts/`
