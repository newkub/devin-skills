# Dashboard Review

## Goal

ตรวจ dashboard จากมุม stakeholder — โฟกัส scannability, data clarity และ action readiness

## Checklist

- KPI/สถิติสำคัญอยู่ตำแหน่งแรกที่สายตามองเห็น
- Data density เหมาะสม — ไม่แน่นเกินจนอ่านไม่ออก
- Table มี sorting, filtering, และ pagination ครบ
- Chart มี axis labels, units และ legend ชัดเจน
- Empty state บอกวิธีเริ่มต้น ไม่ใช่หน้าว่าง
- Filter/search อยู่ใกล้ data ที่มันกระทบ
- Realtime/auto-refresh มี indicator ว่าข้อมูลล่าสุดเมื่อไร
- สีของ metrics สื่อทิศทาง (เขียวดี/แดงแย่) สม่ำเสมอ

## Common Issues

- ตัวเลขใหญ่แต่ไม่มี context (เทียบกับอะไร, ช่วงเวลาไหน)
- Chart ใช้สีที่ colorblind แยกไม่ออก
- Actions ที่สำคัญถูกซ่อนใน overflow menu
