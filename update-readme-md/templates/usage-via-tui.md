## Usage via TUI

<details>
<summary>TUI keyboard shortcuts & layout</summary>

1. Open a terminal and run `bunx <package> tui`
2. Use `↑`/`↓` to select an action, `Enter` to confirm, `q` to quit

```text
┌──────────────────────────────────────────────────────────┐
│  my-app — Main Menu                                      │
│                                                          │
│  > Generate resource        [Enter]                      │
│    View history             [↑/↓]                        │
│    Settings                 [q]  quit                    │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

</details>
