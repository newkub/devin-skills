# review-issue — Full Dimension Checklist

## 1. Completeness

- [ ] problem description ชัด, expected vs actual
- [ ] reproduction steps ทำตามได้, environment noted
- [ ] logs/screenshots/version info attached

## 2. Quality

- [ ] single issue per ticket, scope bounded
- [ ] duplicates searched, related issues linked
- [ ] labels/type/priority ถูกต้อง

## 3. Actionability

- [ ] acceptance criteria / definition of done
- [ ] affected components identified
- [ ] workaround noted ถ้ามี

## 4. Triage Signals

- [ ] severity justified by impact
- [ ] user-facing vs internal, regression?
- [ ] effort estimate reasonable

## Scoring

- pass = 1, warning = 0.5, fail = 0; grade A (90+), B (80+), C (70+), D (60+), F (<60)
