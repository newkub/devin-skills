# Ratatui TUI Template

## Structure

- `src/main.rs` — entrypoint
- `src/app.rs` — state management
- `src/ui.rs` — render widgets
- `src/events.rs` — event loop
- `Cargo.toml` — dependencies

## Dependencies

```toml
[dependencies]
crossterm = "0.28"
ratatui = "0.29"
```

## Setup

1. Copy to `apps/tui/<app-name>/`
2. Replace `<app-name>`
3. รัน `cargo run`
