# Lib Zod API & Dependencies

## Install

```sh
bun add -D zod
# or
npm install --save-dev zod
```

## Version

- Latest: 4.5.4
- [Package Registry](https://www.npmjs.com/package/zod)
- [Repository](https://github.com/colinhacks/zod)

- See package registry for transitive dependencies.

## Common API / Commands

| commands | description | default | options |
|---|---|---|---|
| `install` | Install zod in project | latest version | --save-dev, --save, --global |
| `import` | Import from 'zod' | default or named | (none) |
| `configure` | Configure project settings | project defaults | --config, --file |
| `use` | Use the main API / runtime | as documented | (none) |
| `import 'zod/v3'` | Subpath export for v3 | entry as documented | (none) |
| `import 'zod/v4'` | Subpath export for v4 | entry as documented | (none) |
| `import 'zod/mini'` | Subpath export for mini | entry as documented | (none) |
