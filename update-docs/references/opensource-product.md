# Open-Source Product Documentation Reference

Use for open-source *products* — downloadable apps/frameworks/toolchains with end users (not libraries consumed via import). Community-facing.

## Detection

- Public repo, OSS license, end users install/run it (app, framework, platform)
- Has releases/versions + community surface (issues, discussions, contributing)

## Index Links

`Project`, `Getting Started`, `Guides`, `Development`, `References` (configuration, api if embeddable, migration, changelog, security, contributing, license, code-of-conduct)

## Page Groups

- `project/` — overview, features, decisions/, `roadmap/`
- `getting-started/` — quickstart, installation, usage
- `guides/` — task-oriented how-tos per use case
- `development/` — setup, architecture, workflows, testing
- `references/` — `configuration.md`, `commands/` if CLI, `api.md` if embeddable, `migration.md`, `changelog.md`, `security.md`, `contributing.md`, `license.md`, `code-of-conduct.md`

## Content Focus

- `getting-started/quickstart.md` — install → run → visible result
- `guides/*.md` — real user journeys
- `references/contributing.md` — from `/update-contributing`
- `references/comparison.md` — vs alternatives, honest
- `references/migration.md` — version upgrades
