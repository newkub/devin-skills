# CAP Theorem

## คำนิยาม

ระบบ distributed สามารถรับประกันได้เพียง 2 จาก 3 อย่าง:
- **C**onsistency (ความสอดคล้อง): ทุก node เห็นข้อมูลเดียวกันพร้อมกัน
- **A**vailability (ความพร้อมใช้งาน): ทุก request ได้รับ response
- **P**artition Tolerance (ความทนทานต่อการแบ่งส่วน): ระบบทำงานต่อไปแม้มี network partitions

## การแลกเปลี่ยน

| ระบบ | C | A | P | กรณีใช้งาน |
|--------|---|---|---|----------|
| **RDBMS** | ✓ | ✓ | ✗ | Single node, ความสอดคล้องสูง |
| **Cassandra** | ✗ | ✓ | ✓ | ความพร้อมใช้งานสูง, ความสอดคล้องแบบ eventual |
| **MongoDB** | ✓ | ✓ | ✗ | ความสอดคล้องสูง, single node |
| **DynamoDB** | ✓ | ✓ | ✓ | ความสอดคล้องปรับได้ |
