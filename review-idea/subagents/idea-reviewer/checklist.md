# review-idea — Full Dimension Checklist

## 1. Clarity

- [ ] problem statement ชัด, target user ระบุ
- [ ] success criteria measurable, scope bounded
- [ ] assumptions listed explicitly

## 2. Research

- [ ] existing solutions/competitors surveyed
- [ ] prior art ใน codebase, related past work
- [ ] technical constraints identified

## 3. Feasibility

- [ ] technical feasibility: effort, skills, dependencies
- [ ] resource/timeline realistic
- [ ] proof-of-concept needs identified

## 4. Impact And Fit

- [ ] user/business value estimated
- [ ] alignment กับ roadmap/strategy
- [ ] opportunity cost vs alternatives

## 5. Risk And Decision

- [ ] risks: technical, adoption, maintenance
- [ ] reversible vs one-way decisions
- [ ] decision recorded: go/no-go/defer + rationale

## Scoring

- pass = 1, warning = 0.5, fail = 0; grade A (90+), B (80+), C (70+), D (60+), F (<60)
