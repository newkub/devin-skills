# Best Practices

## Computation

- **เลือกอัลกอริทึมที่เหมาะสม**: ไม่ใช่เสมอไปว่า O(n) ดีกว่า O(n²)
- **เขียน clean code**: อ่านง่ายกว่า micro-optimizations
- **เทสต์ edge cases**: ข้อมูลขนาดเล็ก ขนาดใหญ่ และ edge cases

## Discrete Math

- **ใช้ graph algorithms ที่เหมาะสม**: BFS vs DFS
- **เข้าใจ boolean logic**: ลดความซับซ้อนของ conditions
- **ใช้ combinatorics**: เมื่อต้องการนับจำนวนวิธี

## Information Theory

- **ใช้ entropy**: เพื่อวัดความไม่แน่นอนของข้อมูล
- **เลือก compression algorithm**: ตามประเภทข้อมูล
- **ใช้ error correction**: เมื่อความถูกต้องสำคัญ

## Linear Algebra

- **ใช้ libraries**: ไม่ต้อง implement เอง
- **เข้าใจ matrix operations**: สำคัญสำหรับ ML
- **ตรวจสอบ numerical stability**: หลีกเลี่ยง floating point errors

## Set Theory

- **ใช้ set operations**: สำหรับ data filtering
- **เข้าใจ cardinality**: สำคัญสำหรับ database design
- **ใช้ Venn diagrams**: เพื่อ visualize ความสัมพันธ์
