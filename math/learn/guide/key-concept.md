# Key Concepts

## Computation

- **Algorithms**: ขั้นตอนการแก้ปัญหาที่เป็นระบบ
- **Complexity**: การวิเคราะห์ประสิทธิภาพของอัลกอริทึม
- **Recursion**: การเรียกตัวเองซ้ำ
- **Dynamic Programming**: การแก้ปัญหาโดยแบ่งย่อย

## Discrete Mathematics

- **Set Theory**: ทฤษฎีเซต - การรวมกลุ่มของวัตถุ
- **Logic**: ตรรกศาสตร์ - การให้เหตุผล
- **Graph Theory**: ทฤษฎีกราฟ - การเชื่อมโยง
- **Combinatorics**: การจัดหมู่และการนับ

## Information Theory

- **Entropy**: การวัดความไม่แน่นอนของข้อมูล
- **Coding**: การเข้ารหัสข้อมูล
- **Compression**: การบีบอัดข้อมูล
- **Channel Capacity**: ความจุของช่องทางส่งสัญญาณ

## Linear Algebra

- **Vectors**: เวกเตอร์ - ปริมาณที่มีทิศทาง
- **Matrices**: เมทริกซ์ - อาร์เรย์ของตัวเลข
- **Linear Transformations**: การแปลงเชิงเส้น
- **Eigenvalues**: ค่าเฉพาะของเมทริกซ์

## Set Theory

- **Sets**: เซต - กลุ่มของวัตถุ
- **Operations**: การดำเนินการบนเซต
- **Relations**: ความสัมพันธ์ระหว่างเซต
- **Functions**: ฟังก์ชัน - การแมปจากเซตหนึ่งไปอีกเซตหนึ่ง
