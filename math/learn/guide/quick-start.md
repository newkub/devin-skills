# Quick Start

## เริ่มต้นกับคณิตศาสตร์สำหรับการพัฒนาซอฟต์แวร์

### 1. Computation

เรียนรู้ Big O Notation เพื่อวิเคราะห์ประสิทธิภาพ:
- O(1) - Constant time
- O(n) - Linear time
- O(log n) - Logarithmic time
- O(n²) - Quadratic time

### 2. Discrete Math

เรียนรู้พื้นฐาน:
- Boolean logic สำหรับ conditional statements
- Graph theory สำหรับ data structures
- Combinatorics สำหรับ algorithm analysis

### 3. Information Theory

เรียนรู้:
- Entropy สำหรับ data compression
- Coding สำหรับ error detection

### 4. Linear Algebra

เรียนรู้:
- Vectors สำหรับ machine learning
- Matrices สำหรับ graphics และ ML

### 5. Set Theory

เรียนรู้:
- Set operations สำหรับ database queries
- Relations สำหรับ data modeling
