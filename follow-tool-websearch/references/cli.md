# Web Search CLI

## Install

```sh
bun add -D @websearch/cli # see docs
```

## Version

- Latest
- Repository: https://github.com/websearch/cli
- Docs: https://github.com/websearch/cli

## Commands

| commands | description | default | options |
|---|---|---|---|
| `websearch <query>` | Search the web | — | --limit, --engine, --json |
| `websearch --help` | Show help | — | (none) |

## Notes

Web search tooling varies; this skill may use built-in Devin web tools rather than a local CLI.
