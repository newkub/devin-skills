# Zig CLI Reference

## Essential Commands

| Command | Description |
|---------|-------------|
| `zig build` | Build project |
| `zig run` | Build and run project |
| `zig test` | Run tests |
| `zig fmt` | Format code |
| `zig build-exe` | Build executable |
| `zig build-lib` | Build library |
| `zig build-obj` | Build object file |
| `zig translate-c` | Translate C to Zig |
| `zig init-exe` | Initialize executable project |
| `zig init-lib` | Initialize library project |

## Build Commands

| Command | Description |
|---------|-------------|
| `zig build` | Debug build |
| `zig build -Drelease-fast` | Release fast build |
| `zig build -Drelease-safe` | Release safe build |
| `zig build -Drelease-small` | Release small build |

## Test Commands

| Command | Description |
|---------|-------------|
| `zig test` | Run all tests |
| `zig test <file>` | Run specific test file |
| `zig test --test-filter <name>` | Run specific test |
