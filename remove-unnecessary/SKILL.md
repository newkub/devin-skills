## Goal

ลบสิ่งที่ไม่จำเป็นออกจากสถานการณ์ปัจจุบัน เพื่อให้เหลือแต่สิ่งที่จำเป็นจริงๆ

## Scope

ใช้ได้กับทุก context — งาน ไฟล์ ขั้นตอน dependencies การตัดสินใจ หรือสิ่งของ — ที่ไม่ได้ใช้ ไม่จำเป็น หรือซ้ำซ้อน

## Execute

1. ระบุสิ่งที่ไม่จำเป็น — สิ่งที่ไม่ได้ใช้ ซ้ำซ้อน เกินความจำเป็น หรือไม่สร้าง value
2. ตรวจสอบความปลอดภัย — ยืนยันว่าลบแล้วไม่กระทบสิ่งที่จำเป็น
3. ลบหรือลด — นำออก รวบรวม หรือยกเลิกสิ่งที่ไม่จำเป็น
4. อัปเดทสิ่งที่เกี่ยวข้อง — ปรับ references, links, ขั้นตอน หรือ dependencies ที่เชื่อมโยง
5. ตรวจสอบผล — ยืนยันว่าหลังลบยังทำงานได้ตามเป้าหมาย

## Rules

- ไม่ลบสิ่งที่มี dependency หรือ impact ที่ยังจำเป็น
- ตรวจสอบก่อนลบเสมอ โดยเฉพาะสิ่งที่เสี่ยงหรือยากจะกู้คืน
- ลบทีละขั้นตอนเมื่อเป็นเรื่องสำคัญ
- อัปเดทสิ่งที่เชื่อมโยงหลังลบ

## Expected Outcome

- สิ่งที่ไม่จำเป็นถูกลบหรือลดลง
- ไม่มีสิ่งที่เสียหายจากการลบ
- ระบบหรืองานยังทำงานได้ตามเป้าหมาย
