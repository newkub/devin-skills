## CPU Execution Flow

### Instruction Processing

```text
┌─────────────────────────────────────────────────────────────────┐
│              Instruction Processing Pipeline                     │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│   1. FETCH                                                        │
│      ┌─────────────────────────────────────────┐                │
│      │ PC → MAR → Memory → MDR → IR              │                │
│      │                                          │                │
│      │ Program Counter holds next instruction   │                │
│      │ address to fetch                         │                │
│      └─────────────────────────────────────────┘                │
│                          │                                       │
│                          ▼                                       │
│   2. DECODE                                                         │
│      ┌─────────────────────────────────────────┐                │
│      │ IR → Control Unit → Signals              │                │
│      │                                          │                │
│      │ Parse opcode and operands                │                │
│      │ Generate control signals                  │                │
│      └─────────────────────────────────────────┘                │
│                          │                                       │
│                          ▼                                       │
│   3. FETCH OPERANDS                                                 │
│      ┌─────────────────────────────────────────┐                │
│      │ Register File → Read Rs, Rt              │                │
│      │ Immediate → Sign extend if needed        │                │
│      └─────────────────────────────────────────┘                │
│                          │                                       │
│                          ▼                                       │
│   4. EXECUTE                                                         │
│      ┌─────────────────────────────────────────┐                │
│      │ ALU Operation or Address Calculation     │                │
│      │                                          │                │
│      │ - Arithmetic/Logical: ALU result        │                │
│      │ - Load/Store: Effective address          │                │
│      │ - Branch: Compare and target address     │                │
│      └─────────────────────────────────────────┘                │
│                          │                                       │
│                          ▼                                       │
│   5. MEMORY ACCESS (if needed)                                     │
│      ┌─────────────────────────────────────────┐                │
│      │ For Load: Memory → Data                  │                │
│      │ For Store: Data → Memory                 │                │
│      └─────────────────────────────────────────┘                │
│                          │                                       │
│                          ▼                                       │
│   6. WRITE BACK                                                     │
│      ┌─────────────────────────────────────────┐                │
│      │ Result → Register File                   │                │
│      │ Update PC (if branch)                    │                │
│      └─────────────────────────────────────────┘                │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

## I/O System

### Polling vs Interrupt vs DMA

```text
┌─────────────────────────────────────────────────────────────────┐
│                    I/O Techniques                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│   1. Polling (Programmed I/O)                                    │
│   ┌─────────────────────────────────────────────────────────┐   │
│   │ while (status != READY) { /* wait */ }                  │   │
│   │ data = read(DATA_REG);                                  │   │
│   └─────────────────────────────────────────────────────────┘   │
│   - Simple but CPU intensive                                    │
│   - Good for slow devices                                       │
│                                                                  │
│   2. Interrupt-Driven I/O                                       │
│   ┌─────────────────────────────────────────────────────────┐   │
│   │ Main Program    ─────▶│     Interrupt Handler          │   │
│   │      │                │           │                     │   │
│   │      │                │     Process data                │   │
│   │      │                │           │                     │   │
│   │      ▼                │           ▼                     │   │
│   │   Continue            └───── Return to main              │   │
│   └─────────────────────────────────────────────────────────┘   │
│   - CPU can do other work while waiting                         │
│   - Good for moderate-speed devices                             │
│                                                                  │
│   3. DMA (Direct Memory Access)                                 │
│   ┌─────────────────────────────────────────────────────────┐   │
│   │ CPU ────▶ Setup DMA ────▶ DMA transfers ────▶ Interrupt  │   │
│   │      │                      │              │              │   │
│   │      │                      ▼              ▼              │   │
│   │      │                ┌────────────┐  ┌───────────┐      │   │
│   │      │                │   Memory   │  │  CPU      │      │   │
│   │      │                │   Direct   │  │  Free     │      │   │
│   │      │                └────────────┘  └───────────┘      │   │
│   │      │                       │              │              │   │
│   │      └───────────────────────┴──────────────┘              │   │
│   └─────────────────────────────────────────────────────────┘   │
│   - CPU only sets up transfer, DMA handles it                    │
│   - Good for high-speed devices (disk, network)                  │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

## Parallel Processing

### Flynn's Taxonomy

```text
┌─────────────────────────────────────────────────────────────────┐
│                    Flynn's Taxonomy                               │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│   ┌────────────────┬───────────────────────────────────────┐   │
│   │   SISD         │   Single Instruction, Single Data     │   │
│   │                │   - Traditional single-core CPU       │   │
│   │   ┌──────┐     │   - One instruction at a time         │   │
│   │   │   ▼  │     │   - One data stream                   │   │
│   │   └──────┘     │                                       │   │
│   └────────────────┴───────────────────────────────────────┘   │
│                                                                  │
│   ┌────────────────┬───────────────────────────────────────┐   │
│   │   SIMD         │   Single Instruction, Multiple Data  │   │
│   │                │   - GPUs, Vector processors           │   │
│   │   ┌──────┐     │   - One instruction, many data        │   │
│   │   │   ▼  │     │   - Parallel ALUs                     │   │
│   │   └──────┘     │                                       │   │
│   │   ┌──┬──┬──┐   │                                       │   │
│   │   │  │  │  │   │                                       │   │
│   │   └──┴──┴──┴──┘   │                                       │   │
│   └────────────────┴───────────────────────────────────────┘   │
│                                                                  │
│   ┌────────────────┬───────────────────────────────────────┐   │
│   │   MISD         │   Multiple Instruction, Single Data   │   │
│   │                │   - Rarely used                       │   │
│   │   ┌────┐┌────┐ │   - Fault tolerance                   │   │
│   │   │ ▼  ││ ▼  │ │                                       │   │
│   │   └────┘└────┘ │                                       │   │
│   └────────────────┴───────────────────────────────────────┘   │
│                                                                  │
│   ┌────────────────┬───────────────────────────────────────┐   │
│   │   MIMD         │   Multiple Instruction, Multiple Data  │   │
│   │                │   - Multi-core CPUs                   │   │
│   │   ┌────┐┌────┐ │   - Distributed systems               │   │
│   │   │ ▼  ││ ▼  │ │   - Independent instruction streams    │   │
│   │   └──┬─┘└──┬─┘ │                                       │   │
│   │      │     │   │                                       │   │
│   │      ▼     ▼   │                                       │   │
│   │   ┌────┐┌────┐ │                                       │   │
│   │   └────┘└────┘ │                                       │   │
│   └────────────────┴───────────────────────────────────────┘   │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```
