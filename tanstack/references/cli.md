# CLI

## TanStack Router CLI

### Generate Route

```bash
npx @tanstack/router-cli generate
```

### Type Check Routes

```bash
npx @tanstack/router-cli typecheck
```

## TanStack Start CLI

### Create Project

```bash
npx create-tanstack-start-app@latest
```

### Dev Server

```bash
bun run dev
```

### Build

```bash
bun run build
```
