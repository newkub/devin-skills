# Installation

## Install Individual Packages

```bash
bun add @tanstack/react-query
bun add @tanstack/react-table
bun add @tanstack/react-router
bun add @tanstack/react-form
bun add @tanstack/react-store
bun add @tanstack/start
```

## Install All

```bash
bun add @tanstack/react-query @tanstack/react-table @tanstack/react-router @tanstack/react-form @tanstack/react-store @tanstack/start
```

## Peer Dependencies

- React 18+
- TypeScript (recommended)
