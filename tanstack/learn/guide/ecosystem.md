# Ecosystem

## Official Libraries

- **TanStack Query** - Data fetching
- **TanStack Table** - Headless table
- **TanStack Router** - Type-safe router
- **TanStack Form** - Form handling
- **TanStack Store** - State management
- **TanStack Start** - Full-stack framework

## Integrations

- **React** - ใช้กับ React 18+
- **Next.js** - ใช้กับ Next.js (SSR, SSG)
- **Vite** - ใช้กับ Vite
- **TypeScript** - Full TypeScript support
- **SolidJS** - TanStack Query มี SolidJS adapter
- **Vue** - TanStack Query มี Vue adapter
- **Svelte** - TanStack Query มี Svelte adapter

## Community Tools

- **TanStack DevTools** - DevTools extension สำหรับ debugging
- **React Query DevTools** - DevTools สำหรับ TanStack Query
