# Features

## TanStack Query

- **Caching** - Automatic caching ด้วย stale-while-revalidate
- **Synchronization** - Sync data ระหว่าง tabs/windows
- **Pagination** - Infinite query และ cursor-based pagination
- **Optimistic Updates** - Update UI ก่อน server response
- **Retry** - Automatic retry พร้อม exponential backoff

## TanStack Table

- **Sorting** - Multi-column sorting
- **Filtering** - Client และ server-side filtering
- **Pagination** - Client และ server-side pagination
- **Virtualization** - Row virtualization สำหรับ large tables
- **Column Resizing** - Drag-to-resize columns

## TanStack Router

- **Type Safety** - Full TypeScript support
- **Data Loading** - Loaders และ actions
- **Route Groups** - Organize routes
- **Search Params** - Type-safe search params
