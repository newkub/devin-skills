# Type Safety

## TypeScript Integration

TanStack libraries ออกแบบมาเพื่อ TypeScript:
- **Full type inference** - types ถูก infer อัตโนมัติ
- **No any types** - หลีกเลี่ยง `any` ให้มากที่สุด
- **Strict mode** - ใช้ strict mode ใน tsconfig

## Type-Safe Data

- **Query types** - infer types จาก query functions
- **Mutation types** - infer types จาก mutation functions
- **Form types** - infer types จาก schemas

## Type-Safe Routing

- **Route params** - type-safe route params
- **Search params** - type-safe search params
- **Loader data** - type-safe loader data
