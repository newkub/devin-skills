# Service Vercel API & Dependencies

## Install

```sh
bun add -D vercel
# or
npm install --save-dev vercel
```

## Version

- [Package Registry](https://www.npmjs.com/package/vercel)

- See package registry for transitive dependencies.

## Common API / Commands

| commands | description | default | options |
|---|---|---|---|
| `install` | Install vercel in project | latest version | --save-dev, --save, --global |
| `vc` | Run the vc CLI | current workspace | --help, --version, --config |
| `vercel` | Run the vercel CLI | current workspace | --help, --version, --config |
| `configure` | Configure via config file | project defaults | --config, --file |
