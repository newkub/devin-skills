| Command | Description | Options |
|---|---|---|
| `capgo init` | Initialize config | --apikey, --force |
| `capgo login` | Login / set API key | --apikey |
| `capgo app add` | Register an app on Capgo | --name, --icon |
| `capgo bundle upload` | Upload a web bundle | --channel, --path, --external |
| `capgo bundle list` | List bundles | --channel |
| `capgo channel set` | Assign a bundle to a channel | --channel, --latest |
| `capgo channel delete` | Remove a channel | --channel |
| `capgo key save` / `key delete` | Manage update signing keys | --key |
