# Biome Features

## Core Features

### Formatter

- **Fast**: Written in Rust, 10-20x faster than Prettier
- **Multi-language**: JavaScript, TypeScript, JSX, TSX, JSON, CSS, HTML, GraphQL
- **Safe**: Never changes code behavior
- **Configurable**: Customizable formatting rules

### Linter

- **200+ rules**: Comprehensive linting coverage
- **Categories**: Accessibility, complexity, correctness, performance, security, style, suspicious
- **Safe fixes**: Automatic fixes for many issues
- **Type-aware**: TypeScript-specific rules

### Import Organization

- **Automatic**: Sort and group imports
- **Deduplication**: Remove duplicate imports
- **Configurable**: Custom import ordering

## Advanced Features

### Editor Integration

- **LSP Support**: Real-time feedback in editors
- **VS Code Extension**: Full IDE integration
- **Neovim Plugin**: Vim integration
- **IntelliJ Plugin**: JetBrains IDEs support

### CI/CD

- **CI Mode**: Non-interactive for CI pipelines
- **GitHub Actions**: Native integration
- **Reporters**: JSON, GitHub annotations, default output
- **Exit Codes**: Clear status reporting

### Migration Tools

- **ESLint Migration**: Convert ESLint configs
- **Prettier Migration**: Convert Prettier configs
- **Automatic**: One-command migration

## Performance

- **Parallel Processing**: Multi-core utilization
- **Incremental**: Only check changed files
- **Caching**: Smart caching for faster runs
- **Low Memory**: Efficient resource usage

## Developer Experience

- **Fast Feedback**: Instant results
- **Clear Errors**: Helpful error messages
- **Safe Fixes**: Confidence in auto-fixes
- **Config Validation**: Schema-based config checking
