# ฟีเจอร์ต่างๆ

## Core Features

### Multiple Version Support
- ติดตั้ง multiple versions ของ tool เดียวกัน
- Switch versions ตาม project อัตโนมัติ
- ไม่มี conflicts ระหว่าง versions

### Auto-Installation
- Auto-install tools เมื่อต้องการ
- Cache downloaded files สำหรับ speed
- Parallel installation สำหรับ multiple tools

### Project Isolation
- แต่ละ project มี environment ของตัวเอง
- ไม่มี side effects ระหว่าง projects
- Clean separation ของ dependencies

### Shell Integration
- Automatic PATH modification
- Environment variable injection
- Support หลาย shell types

## Advanced Features

### CI Integration
- ใช้ใน CI/CD pipelines
- Deterministic builds
- Easy setup ด้วย single command

### Plugin Ecosystem
- 100+ plugins สำหรับ popular tools
- Custom plugin support
- Community-maintained

### Configuration Flexibility
- TOML, YAML, JSON support
- Multiple config files
- Inheritance ระหว่าง configs
