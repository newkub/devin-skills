# Lib Drizzle API & Dependencies

## Install

```sh
bun add -D drizzle-orm
# or
npm install --save-dev drizzle-orm
```

## Version

- Latest: 0.45.2
- [Package Registry](https://www.npmjs.com/package/drizzle-orm)

## Common API / Commands

| commands | description | default | options |
|---|---|---|---|
| `install` | Install drizzle-orm in project | latest version | --save-dev, --save, --global |
| `import` | Import from 'drizzle-orm' | default or named | (none) |
| `configure` | Configure project settings | project defaults | --config, --file |
| `use` | Use the main API / runtime | as documented | (none) |
| `import 'drizzle-orm/d1'` | Subpath export for d1 | entry as documented | (none) |
| `import 'drizzle-orm/gel'` | Subpath export for gel | entry as documented | (none) |
| `import 'drizzle-orm/sql'` | Subpath export for sql | entry as documented | (none) |
| `import 'drizzle-orm/knex'` | Subpath export for knex | entry as documented | (none) |
| `import 'drizzle-orm/neon'` | Subpath export for neon | entry as documented | (none) |
| `import 'drizzle-orm/alias'` | Subpath export for alias | entry as documented | (none) |
| `import 'drizzle-orm/batch'` | Subpath export for batch | entry as documented | (none) |
| `import 'drizzle-orm/table'` | Subpath export for table | entry as documented | (none) |
| `import 'drizzle-orm/utils'` | Subpath export for utils | entry as documented | (none) |
| `import 'drizzle-orm/casing'` | Subpath export for casing | entry as documented | (none) |
