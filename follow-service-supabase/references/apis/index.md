# Service Supabase API & Dependencies

## Install

```sh
bun add -D supabase
# or
npm install --save-dev supabase
```

## Version

- Latest: 2.116.0
- [Package Registry](https://www.npmjs.com/package/supabase)
- [Repository](https://github.com/supabase/cli)

## Dependencies

- See package registry for transitive dependencies.

## Common API / Commands

| commands | description | default | options |
|---|---|---|---|
| `install` | Install supabase in project | latest version | --save-dev, --save, --global |
| `supabase` | Run the supabase CLI | current workspace | --help, --version, --config |
| `configure` | Configure via config file | project defaults | --config, --file |
