# All Features

## Core Features

| Feature | Description |
|---------|-------------|
| **Modal Editing** | Normal, Insert, Visual, Command modes |
| **Multiple Buffers** | Edit multiple files simultaneously |
| **Window Splitting** | Horizontal and vertical splits |
| **Tabs** | Multiple workspaces |
| **Registers** | 10 register types for copying/pasting |
| **Macros** | Record and replay actions |

## Advanced Features

| Feature | Description |
|---------|-------------|
| **LSP Native** | Built-in Language Server Protocol client |
| **Treesitter** | Modern syntax highlighting |
| **Built-in Terminal** | Integrated terminal emulator |
| **Floating Windows** | Popup windows for UI |
| **Completion** | Built-in completion system |
| **Fuzzy Finder** | Via plugins (Telescope) |

| Feature | Description |
