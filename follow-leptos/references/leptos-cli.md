# CLI Commands

Command-line interface for leptos

## Installation

```bash
bun install -g leptos
```

## Commands

| Command | Description | Example |
|----------|-------------|---------|
| command1 | Description | `leptos command1` |
| command2 | Description | `leptos command2 --option` |

## Options

```bash
leptos --help
```

## Examples

```bash
# Example 1
leptos build

# Example 2
leptos serve --port 3000
```
