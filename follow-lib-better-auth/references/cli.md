| Command | Description | Options |
|---------|-------------|---------|
| `bunx auth@latest init` | Scaffold Better Auth in a Next.js project | — |
| `bunx auth@latest generate` | Generate schema/migration from the `auth.ts` config | `--adapter prisma`, `--adapter drizzle`, `--output`, `-y` |
| `bunx auth@latest migrate` | Apply migrations (built-in Kysely adapter only) | — |
| `bunx auth@latest upgrade` | Upgrade the `better-auth` and `@better-auth/*` packages | — |
| `bunx auth@latest secret` | Generate a secure `BETTER_AUTH_SECRET` | — |
