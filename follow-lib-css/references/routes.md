## Key Concepts

- Baseline `Widely available` = feature ครบใน Chrome, Edge, Firefox, Safari (รวม mobile) — safe ใช้โดยไม่ต้อง fallback
- ใช้ `@supports` สำหรับ progressive enhancement เมื่อ feature ยังไม่ Baseline
