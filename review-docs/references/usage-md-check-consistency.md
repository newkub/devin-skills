# Check Consistency

## Goal

เปรียบเทียบกับ project

## Checks

1. เปรียบเทียบ version กับ `package.json`
2. เปรียบเทียบ bin/scripts กับ `package.json`
3. เปรียบเทียบ examples กับ test files หรือ `examples/`
4. เปรียบเทียบ API กับ exports ใน `src/index.ts`
