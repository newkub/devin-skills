# Instantdb cli

## Instant CLI Reference

| Command | Description |
|---|---|
| `bunx instant-cli@latest login` | Authenticate with Instant account |
| `bunx instant-cli@latest logout` | Remove local authentication token |
| `bunx instant-cli@latest init` | Pick/create app and generate `instant.schema.ts` and `instant.perms.ts` |
| `bunx instant-cli@latest push schema` | Push schema changes to the app |
| `bunx instant-cli@latest push perms` | Push permission changes to the app |
| `bunx instant-cli@latest push` | Push both schema and permissions |
| `bunx instant-cli@latest pull` | Pull latest schema and perms from the app |
| `bunx instant-cli@latest status` | Show app connection status |
| `bunx create-instant-app --next` | Scaffold Next.js app with Instant |
| `bunx create-instant-app --vite_react` | Scaffold Vite React app with Instant |

For latest commands see https://www.instantdb.com/docs/cli
