## Community Plugins

### SQL Plugin

```bash
bun install @tauri-apps/plugin-sql
```

**Features**
- SQLite database
- Query execution
- Transaction support

### Store Plugin

```bash
bun install @tauri-apps/plugin-store
```

**Features**
- Persistent key-value storage
- JSON serialization
- Cross-platform

### Global Shortcut Plugin

```bash
bun install @tauri-apps/plugin-global-shortcut
```

**Features**
- Register global hotkeys
- Keyboard shortcuts
- Cross-platform
