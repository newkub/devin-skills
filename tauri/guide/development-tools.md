## Tauri CLI

```bash
# Development
bun run tauri dev

# Build
bun run tauri build

# Info
bun run tauri info
```

## VS Code Extensions

- **Tauri** - Official Tauri support
- **rust-analyzer** - Rust language server
- **Volar** - Vue 3 support
- **ESLint** - JavaScript linting
