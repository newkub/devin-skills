## IPC Mechanism

```
┌─────────────────────────────────────────────────────────────────┐
│                        IPC Flow                                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                   │
│  Frontend                          Rust Backend                  │
│  ────────                          ─────────────                 │
│                                                                   │
│  invoke('cmd', {arg: 'x'})                                        │
│          │                                                        │
│          ▼                                                        │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │              Tauri IPC Layer                             │    │
│  │                                                         │    │
│  │  1. Serialize arguments (JSON)                          │    │
│  │  2. Send message to Rust                                │    │
│  │  3. Rust executes command                               │    │
│  │  4. Serialize response (JSON)                          │    │
│  │  5. Return to frontend                                 │    │
│  │                                                         │    │
│  └─────────────────────────────────────────────────────────┘    │
│          │                                                        │
│          ▼                                                        │
│  Returns: { result: 'value' }                                     │
│                                                                   │
└─────────────────────────────────────────────────────────────────┘
```

```
│                                                                   │
└─────────────────────────────────────────────────────────────────┘
```

## Multi-Platform Build

| Platform | Output | Bundles |
|----------|--------|---------|
| **Windows** | .exe, .msi | NSIS, WiX |
| **macOS** | .app, .dmg | DMG, App, IPA |
| **Linux** | AppImage, deb, rpm | AppImage, deb, rpm |
| **Android** | .apk, .aab | APK, AAB |
| **iOS** | .app | IPA |
