## Permission Denied

**Cause**: Capability ไม่ได้ grant

**Solution**: เพิ่ม permission ใน capability file

## Path Not Found

**Cause**: Path ไม่ถูกต้อง

**Solution**: ใช้ path API สำหรับ resolve paths

## API Not Available

**Cause**: Plugin ไม่ได้ติดตั้ง

**Solution**: ติดตั้ง plugin ที่จำเป็น
