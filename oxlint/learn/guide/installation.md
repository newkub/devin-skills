# Installation

## Description

ติดตั้ง Oxlint สำหรับ JavaScript/TypeScript linting

## Steps

### Using bun

```bash
bun install -D oxlint
```

### Using bun

```bash
bun add -D oxlint
```

### Using yarn

```bash
yarn add -D oxlint
```

### Using bun

```bash
bun add -D oxlint
```

## Verify Installation

```bash
npx oxlint --version
# or
bunx oxlint --version
```

## Global Installation

```bash
bun install -g oxlint
```

## Best Practices

1. **Install as Dev Dependency**: ติดตั้งเป็น dev dependency
2. **Use Package Manager**: ใช้ package manager ที่ project ใช้
3. **Version Pin**: Pin version สำหรับ consistency
4. **Update Regularly**: Update เป็นประจำ
