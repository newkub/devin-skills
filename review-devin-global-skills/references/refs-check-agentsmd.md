## Checks

1. เปรียบเทียบรายการ skills กับ `AGENTS.md`

3. ระบุ entries ใน `AGENTS.md` ทีไม่มี skill directory ตรงกัน
4. ตรวจ category ว่าสอดคล้องกับ prefix/name
