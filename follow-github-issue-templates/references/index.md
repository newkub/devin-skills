# GitHub Issue Templates

รายการ issue templates สำหรับ `.github/ISSUE_TEMPLATE/`

## Templates

- `bug_report.yml` — รายงาน bug หรือ unexpected behavior
- `feature_request.yml` — เสนอ feature หรือ enhancement
- `plan.yml` — เสนอ plan, roadmap หรือ epic
- `test.yml` — ขอหรือรายงาน test scenario
- `questions.yml` — ถามคำถามหรือเปิด discussion
- `agents_task.yml` — สร้าง task สำหรับ AI agent
- `config.yml` — กำหนด blank issues และ contact links

## Labels

ตรวจสอบว่า repo มี labels ต่อไปนี้ก่อน deploy templates:

- `bug`
- `feature`
- `plan`
- `test`
- `question`
- `agents-task`
