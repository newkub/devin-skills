# Create Tauri Plugins API & Dependencies

## Install

```sh
bun add -D @tauri-apps/api/core
# or
npm install --save-dev @tauri-apps/api/core
```

## Version

- Latest: see registry
- [Package Registry](https://www.npmjs.com/package/@tauri-apps/api/core)


## Dependencies

- See package registry for transitive dependencies.

## Common API / Commands

| commands | description | default | options |
|---|---|---|---|
| `install` | Install @tauri-apps/api/core in project | latest version | --save-dev, --save, --global |
| `import` | Import from '@tauri-apps/api/core' | default or named | (none) |
| `configure` | Configure project settings | project defaults | --config, --file |
| `use` | Use the main API / runtime | as documented | (none) |
