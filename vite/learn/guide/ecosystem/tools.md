# Tools

## 1. CLI Tools

### Vite CLI

```bash
# Create new project
bunx create-vite my-app

# Preview production build
bunx vite preview

# Optimize dependencies
bunx vite optimize
```

### Vitest CLI

```bash
# Run tests
bunx vitest

# Run tests with UI
bunx vitest --ui

# Run tests in watch mode
bunx vitest --watch
```
