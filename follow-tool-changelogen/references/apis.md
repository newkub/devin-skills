# Tool Changelogen API & Dependencies

## Install

```sh
bun add -D changelogen
# or
npm install --save-dev changelogen
```

## Version

- Latest: 0.6.2
- [Package Registry](https://www.npmjs.com/package/changelogen)
- [Repository](https://github.com/unjs/changelogen)

## Dependencies

- See package registry for transitive dependencies.

## Common API / Commands

| commands | description | default | options |
|---|---|---|---|
| `install` | Install changelogen in project | latest version | --save-dev, --save, --global |
| `changelogen` | Run the changelogen CLI | current workspace | --help, --version, --config |
| `configure` | Configure via config file | project defaults | --config, --file |
