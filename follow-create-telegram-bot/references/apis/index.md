# Create Telegram Bot API & Dependencies

```sh
bun add -D grammy
# or
npm install --save-dev grammy
```

## Common API / Commands

| commands | description | default | options |
|---|---|---|---|
| `install` | Install grammy in project | latest version | --save-dev, --save, --global |
| `import` | Import from 'grammy' | default or named | (none) |
| `configure` | Configure project settings | project defaults | --config, --file |
| `use` | Use the main API / runtime | as documented | (none) |
| `import 'grammy/web'` | Subpath export for web | entry as documented | (none) |
| `import 'grammy/types'` | Subpath export for types | entry as documented | (none) |
