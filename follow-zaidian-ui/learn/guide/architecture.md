# Architecture

## Overall Architecture

```
┌─────────────────────────────────────────────────────────────┐
│                    Application Layer                         │
│                  (Your SolidJS App)                          │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│                    Component Layer                            │
│                  (Zaidan Components)                          │
├─────────────────────────────────────────────────────────────┤
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐         │
│  │   Button    │  │    Card     │  │   Dialog    │         │
│  └─────────────┘  └─────────────┘  └─────────────┘         │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐         │
│  │   Input     │  │   Select    │  │   Table     │         │
│  └─────────────┘  └─────────────┘  └─────────────┘         │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│                    Primitive Layer                            │
│              (Kobalte + Corvu Primitives)                    │
├─────────────────────────────────────────────────────────────┤
│  ┌─────────────┐              ┌─────────────┐               │
│  │   Kobalte   │              │    Corvu    │               │
│  │  Primitives │              │  Primitives │               │
│  └─────────────┘              └─────────────┘               │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│                    Styling Layer                             │
│                      (Tailwind CSS)                           │
├─────────────────────────────────────────────────────────────┤
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐         │
│  │   Colors    │  │  Spacing    │  │ Typography  │         │
│  │  (Tokens)   │  │  (Tokens)   │  │  (Tokens)   │         │
│  └─────────────┘  └─────────────┘  └─────────────┘         │
└─────────────────────────────────────────────────────────────┘
```

### Single Component Structure

```
component-name/
├── index.tsx              # Barrel export
├── component-name.tsx     # Main component
└── types.ts               # Type definitions
```
