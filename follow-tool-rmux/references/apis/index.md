# Tool Rmux API & Dependencies

## Install

```sh
bun add -D rmux
# or
npm install --save-dev rmux
```

## Version

- Latest: 0.0.1-alpha.17
- [Package Registry](https://www.npmjs.com/package/rmux)
- [Repository](https://github.com/nakulbh/rmux)

## Dependencies

- See package registry for transitive dependencies.

## Common API / Commands

| commands | description | default | options |
|---|---|---|---|
| `install` | Install rmux in project | latest version | --save-dev, --save, --global |
| `rmux` | Run the tool CLI | current workspace | see cli.md |
| `configure` | Configure via config file | project defaults | --config, --file |
