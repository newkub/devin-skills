## Goal

อธิบาย ecosystem ของ Node.js และ tools ที่รองรับ

## Scope

สำหรับการพัฒนาด้วย Node.js และ integration กับ tools อื่นๆ

## Core Tools

### Node.js CLI

- `node` - รัน JavaScript files
- `bun` - Package manager
- `npx` - Execute packages
- `node --inspect` - Debugging

### Built-in Modules

- `fs` - File system
- `http`/`https` - HTTP server
- `path` - File paths
- `crypto` - Cryptography
- `events` - Event emitter
- `stream` - Streaming data
- `buffer` - Binary data

## Frameworks ที่นิยม

### Web Frameworks

- **Express** - Minimal web framework
- **Koa** - Next-gen web framework
- **Fastify** - Fast web framework
- **NestJS** - Enterprise framework
- **Hapi** - Configuration-driven framework

### Full-stack Frameworks

- **Next.js** - React framework
- **Nuxt** - Vue framework
- **SvelteKit** - Svelte framework

## Libraries ที่นิยม

### Database

- **Sequelize** - ORM for SQL
- **Mongoose** - MongoDB ODM
- **Knex** - Query builder
- **pg** - PostgreSQL client

### Testing

- **Jest** - Testing framework
- **Mocha** - Test runner
- **Chai** - Assertion library
- **Supertest** - HTTP testing

### Utilities

- **Lodash** - Utility library
- **Moment.js** - Date/time (deprecated, use date-fns)
- **date-fns** - Modern date library
- **Axios** - HTTP client
