# I18n Reference

VitePress locales when docs need multiple languages (e.g. Thai + English).

## Structure

```
docs/
  index.md            # default locale (root)
  en/
    index.md          # /en/ locale
    ...
  .vitepress/config.ts
```

## Config

```ts
export default defineConfig({
  locales: {
    root: { label: 'Thai', lang: 'th' },
    en: {
      label: 'English',
      lang: 'en',
      link: '/en/',
      themeConfig: {
        // same items as Base Nav in templates/nav-config.md, links prefixed /en/
        nav: [
          { text: 'Getting Started', link: '/en/getting-started/installation' },
          { text: 'Guides', link: '/en/guides/', activeMatch: '/en/guides/' },
          { text: 'Examples', link: '/en/examples/', activeMatch: '/en/examples/' },
        ],
      },
    },
  },
})
```

Root locale (`th`) mirrors the same nav with translated `text` (the Thai forms of `Guides`, `Examples`) and unprefixed links — keep one nav source of truth in `templates/nav-config.md`, translate labels only.
    },
  },
})
```

## Rules

- Default locale lives at `docs/` root — extra languages in `docs/<lang>/`
- Mirror the same page structure per locale — no divergent trees
- Do not mix languages inside one page (`/update-docs` rule)
- Only add locales when the project actually ships multi-language content
