# Lib Orpc API & Dependencies

## Install

```sh
bun add -D @orpc/server
# or
npm install --save-dev @orpc/server
```

## Version

- Latest: 1.15.0
- [Package Registry](https://www.npmjs.com/package/@orpc/server)
- [Repository](https://github.com/middleapi/orpc)

## Dependencies

- See package registry for transitive dependencies.

## Common API / Commands

| commands | description | default | options |
|---|---|---|---|
| `install` | Install @orpc/server in project | latest version | --save-dev, --save, --global |
| `import` | Import from '@orpc/server' | default or named | (none) |
| `configure` | Configure project settings | project defaults | --config, --file |
| `use` | Use the main API / runtime | as documented | (none) |
| `import '@orpc/server/ws'` | Subpath export for ws | entry as documented | (none) |
| `import '@orpc/server/node'` | Subpath export for node | entry as documented | (none) |
| `import '@orpc/server/fetch'` | Subpath export for fetch | entry as documented | (none) |
| `import '@orpc/server/bun-ws'` | Subpath export for bun-ws | entry as documented | (none) |
| `import '@orpc/server/crossws'` | Subpath export for crossws | entry as documented | (none) |
| `import '@orpc/server/fastify'` | Subpath export for fastify | entry as documented | (none) |
| `import '@orpc/server/helpers'` | Subpath export for helpers | entry as documented | (none) |
| `import '@orpc/server/plugins'` | Subpath export for plugins | entry as documented | (none) |
| `import '@orpc/server/standard'` | Subpath export for standard | entry as documented | (none) |
| `import '@orpc/server/websocket'` | Subpath export for websocket | entry as documented | (none) |
