# Key Concept

## What is Leptos?

Front-end framework for Rust using a fine-grained reactive system

## Core Features

- **Fine-grained Reactivity**
- **Isomorphic Apps**
- **Server Components**
- **Signal-based**
- **No Virtual DOM**

## When to Use

- When you need Leptos
- For projects requiring Fine-grained Reactivity
- When performance is critical
