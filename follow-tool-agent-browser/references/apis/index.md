# Tool Agent Browser API & Dependencies

## Install

```sh
bun add -D agent-browser
# or
npm install --save-dev agent-browser
```

## Version

- Latest: 0.35.1
- [Package Registry](https://www.npmjs.com/package/agent-browser)
- [Repository](https://github.com/vercel-labs/agent-browser)

## Common API / Commands

| commands | description | default | options |
|---|---|---|---|
| `install` | Install agent-browser in project | latest version | --save-dev, --save, --global |
| `agent-browser` | Run the agent-browser CLI | current workspace | --help, --version, --config |
| `configure` | Configure via config file | project defaults | --config, --file |
