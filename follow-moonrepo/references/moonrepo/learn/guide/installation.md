# Installation

วิธีติดตั้ง moonrepo

## Using Bun (Recommended)

```bash
bun add -D @moonrepo/cli
```

## Using bun

```bash
bun install -D @moonrepo/cli
```

## Using yarn

```bash
yarn add -D @moonrepo/cli
```

## Using bun

```bash
bun add -D @moonrepo/cli
```

## Initialize in Project

```bash
bunx moon init
```

This will:
- Create `moon.yml` configuration file
- Setup project structure
- Initialize moonrepo

## Verify Installation

```bash
bunx moon --version
```

## Uninstall

```bash
bun remove @moonrepo/cli
```
