# Onboarding Review

## Goal

ตรวจ onboarding จากมุม stakeholder — โฟกัส time-to-value และ first impression

## Checklist

- User เห็น value แรกภายในไม่กี่ขั้นตอน
- First-run experience ไม่บังคับ setup ทั้งหมดก่อนใช้งาน
- Progressive disclosure — แนะนำ feature ตาม context ไม่ใช่ tour ยาว
- Empty states ของหน้าหลักชวน user ทำ first action
- Signup/activation flow มี progress และข้ามขั้นไม่จำเป็นได้
- Tooltip/coach marks ปิดได้และไม่กลับมารบกวน
- Sample data หรือ templates ช่วยให้เริ่มเร็ว (ถ้าเหมาะ)
- Checklist/setup progress ให้ความรู้สึกก้าวหน้า

## Common Issues

- Product tour ยาวที่ user skip ทิ้ง
- บังคับกรอกข้อมูลที่ไม่จำเป็นก่อนเห็น value
- ไม่มี guidance เมื่อหน้าหลักว่างเปล่า
