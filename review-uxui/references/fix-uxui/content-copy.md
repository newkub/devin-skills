# Content And Copy Review

## Goal

ตรวจ microcopy จากมุม stakeholder — โฟกัส clarity, tone และการลด friction

## Checklist

- Headline/labels ใช้ภาษาของ user ไม่ใช่ jargon ภายใน
- Button labels บอก outcome ไม่ใช่กลไก ("Save changes" ไม่ใช่ "OK")
- Error messages บอกว่าเกิดอะไร + ทำอะไรต่อได้
- Empty states มี copy ที่ชวน action
- Tone สม่ำเสมอทั้ง app (formal/casual เดียวกัน)
- Numbers/dates format ตรง locale ของ user
- Confirmation dialogs บอกผลกระทบชัดเจน
- ไม่มี Lorem ipsum หรือ placeholder copy ใน production

## Common Issues

- Copy ยาวเกินในปุ่มหรือ label
- ใช้คำซ้ำกันหลายที่หมายถึงคนละอย่าง
- Error code ดิบแสดงให้ user เห็น
