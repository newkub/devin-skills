# Create Browser Extensions API & Dependencies

## Install

```sh
bun add -D webextension-polyfill
# or
npm install --save-dev webextension-polyfill
```

## Version

- Latest: 0.12.0
- [Package Registry](https://www.npmjs.com/package/webextension-polyfill)
- [Repository](https://github.com/mozilla/webextension-polyfill)

## Dependencies

- See package registry for transitive dependencies.

## Common API / Commands

| commands | description | default | options |
|---|---|---|---|
| `install` | Install webextension-polyfill in project | latest version | --save-dev, --save, --global |
| `import` | Import from 'webextension-polyfill' | default or named | (none) |
| `configure` | Configure project settings | project defaults | --config, --file |
| `use` | Use the main API / runtime | as documented | (none) |

## Source

- Official docs: https://github.com/mozilla/webextension-polyfill
- Description: A lightweight polyfill library for Promise-based WebExtension APIs in Chrome.
