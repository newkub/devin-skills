## Component Details

### WebView (Wry)

Wry เป็น WebView abstraction layer:

```rust
// Simplified Wry structure
pub struct WebView {
    window: Window,
    webview: WebViewImpl,
}

impl WebView {
    pub fn new(url: &str) -> Result<Self> {
        // Create platform-specific webview
    }

    pub fn evaluate_script(&self, script: &str) -> Result<()> {
        // Run JavaScript in webview
    }
}
```

### Window Manager (TAO)

TAO จัดการ native windows:

```rust
// Simplified TAO structure
pub struct Window {
    title: String,
    size: Size,
    position: Position,
}

impl Window {
    pub fn new() -> Self { /* ... */ }
    pub fn set_title(&mut self, title: &str) { /* ... */ }
    pub fn set_fullscreen(&mut self, fullscreen: bool) { /* ... */ }
}
```

### IPC Message Flow

```
┌─────────────────────────────────────────────────────────────────┐
│                    IPC Message Flow                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                   │
│  Frontend                    Rust                               │
│  ────────                    ─────                               │
│                                                                   │
│  invoke('cmd', {a: 1})                                           │
│          │                                                        │
│          ▼                                                        │
│  ┌─────────────────┐                                             │
│  │ JSON.serialize  │                                             │
│  │ {cmd: 'cmd',    │                                             │
│  │  args: {a: 1}}  │                                             │
│  └────────┬────────┘                                             │
│           │                                                       │
│           ▼                                                       │
│  ┌─────────────────┐                                             │
│  │   IPC Channel   │                                             │
│  └────────┬────────┘                                             │
│           │                                                       │
│           ▼                                                       │
│  ┌─────────────────┐                                             │
│  │ JSON.deserialize│                                             │
│  └────────┬────────┘                                             │
│           │                                                       │
│           ▼                                                       │
│  ┌─────────────────┐                                             │
│  │ Execute command │                                             │
│  │ fn cmd(a: i32)  │                                             │
│  └────────┬────────┘                                             │
│           │                                                       │
│           ▼                                                       │
│  Return: "result"                                                 │
│                                                                   │
└─────────────────────────────────────────────────────────────────┘
```
