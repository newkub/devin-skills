# review-plan — Full Dimension Checklist

## 1. Completeness

- [ ] objective ชัด, scope in/out ระบุ
- [ ] steps ordered by dependencies, each actionable
- [ ] acceptance criteria per step, done definition

## 2. Risk Assessment

- [ ] technical risks, unknowns, assumptions flagged
- [ ] failure modes + mitigation per high-risk step
- [ ] rollback/abort strategy

## 3. Dependencies

- [ ] external deps: teams, approvals, access, data
- [ ] internal order: foundation → integration → polish
- [ ] parallelizable vs sequential work identified

## 4. Alternatives

- [ ] alternatives considered + why chosen
- [ ] buy vs build, incremental vs rewrite
- [ ] do-nothing option evaluated

## 5. Feasibility

- [ ] effort estimates sane, resource match
- [ ] technical spikes needed identified
- [ ] MVP vs full scope separated

## 6. Validation

- [ ] scope vs acceptance aligned
- [ ] test/verification approach per deliverable
- [ ] success metrics measurable

## Scoring

- pass = 1, warning = 0.5, fail = 0; grade A (90+), B (80+), C (70+), D (60+), F (<60)
