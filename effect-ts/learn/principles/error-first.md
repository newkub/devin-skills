# Error-First Design

## Principle

Effect ออกแบบมาเพื่อ error-first:
- **Explicit Errors** - explicit error handling
- **Type-safe Errors** - typed errors
- **Error Recovery** - error recovery patterns

## Application

- **Handle Errors Explicitly** - handle errors อย่างชัดเจน
- **Use Typed Errors** - ใช้ typed errors
- **Provide Recovery** - provide error recovery mechanisms
