# Functional Programming

## Principle

Effect ออกแบบมาเพื่อ functional programming:
- **Pure Functions** - pure functions สำหรับ business logic
- **Immutability** - immutable data structures
- **Composition** - compose functions ได้

## Application

- **Use Pure Functions** - ใช้ pure functions สำหรับ business logic
- **Avoid Mutations** - หลีกเลี่ยง mutations
- **Compose Effects** - compose effects สำหรับ complex logic
