## Goal

ทำตาม Examples

## Scope

ใช้ `follow-tool-examples` สำหรับ tasks และ workflows เฉพาะที่ครอบคลุม

## Execute

ทำตาม steps และ rules ด้านล่างเพื่อดำเนินการ skill นี้

## Rules

- ทำตาม project conventions และ global rules
- ใช้ tools ที่อนุญาตเฉพาะเมื่อจำเป็น

## Expected Outcome

เสร็จสิ้น `follow-tool-examples` workflow พร้อม output ที่ถูกต้อง
