# How It Works

## TanStack Query

- Cache data ใน memory
- Synchronize data ระหว่าง client และ server
- Auto-refetch เมื่อ data ถูก invalidate
- Handle loading, error, และ success states

## TanStack Table

- Headless component ที่ไม่มี styling
- จัดการ sorting, filtering, pagination ใน logic layer
- Virtualization สำหรับ large datasets
- รองรับ server-side และ client-side operations

## TanStack Router

- Type-safe routes ด้วย TypeScript
- Data loading แบบ parallel และ sequential
- Route-based code splitting
- Search params และ hash routing
